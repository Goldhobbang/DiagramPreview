# 15. 소프트 그라데이션 (Soft Gradients)
> 색이 경계 없이 번지는 것이 주인공. 글래스모피즘(04번)과 구분: 거기서는 그라데이션이 **유리의 배경**, 여기서는 그라데이션 자체가 **전면 콘텐츠**.

**공통 원칙**: 색 정지점(stop) 3개 이내. 인접 색은 색상환에서 90° 이내(그 이상 벌어지면 중간에 탁한 회색 발생). 모든 그라데이션에 **노이즈 4~8% 필수**(밴딩 방지). 텍스트는 그라데이션의 가장 어두운 구간 위에만.

---

## ◾ Variation 1: Peach Dawn (새벽 복숭아 · 수평 지평선)

* **핵심 컬러 (HEX)**: 그라데이션 `#FFB88C → #FF8FA3 → #FF6A88`(180° 수직) · 딥 `#7A2E45` · 크림 `#FFF5EE` · 텍스트 `#FFFFFF` / 딥 텍스트 `#7A2E45`
* **사용 도형 & 그래픽**: **수평 밴드 구조** — 색이 위에서 아래로 흐르는 일출/일몰 지평선. 아주 완만한 호(arc), 얇은 흰색 1px 라인, 반투명 흰 원. 도형 최소, 그라데이션 면이 대부분.
* **표지(Cover) 디자인**
  - 배경 전면 수직 그라데이션(위 `#FFB88C` → 중간 `#FF8FA3` → 아래 `#FF6A88`) + 노이즈 6%.
  - **수평 3분할 지평선 구조**:
    - 상단 30%: 밝은 피치 구간. 여기에 지름 180px 흰색 원(불투명 22%) 하나 — 태양.
    - 중앙 40%: 제목 영역. 제목 중앙 정렬 아님, **좌측 정렬**(좌 여백 96px), 50pt Light `#FFFFFF`, 행간 1.15, 자간 -1%.
    - 하단 30%: 가장 진한 핑크 구간. 아주 완만한 흰색 호(arc, 곡률 반경 화면폭 2.5배)가 좌에서 우로 지나며 하단을 가로지름 — 지평선.
  - 제목 위에 1px 흰색 수평선(폭 80px) + 카테고리 라벨 11pt, 자간 +20%.
  - 호 아래쪽 영역은 그라데이션이 `#FF6A88 → #E0526E`로 한 단계 더 진해짐(수면 반사).
  - 우측 하단에 발표자·날짜 12pt 흰색 80%.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 전폭에 높이 88px 그라데이션 밴드(`#FFB88C → #FF8FA3`, 좌→우 90°) — 표지 색을 가로로 눕힘. 흰 텍스트 섹션명 좌측, 페이지 숫자 우측.
  - **본문 여백**: 좌우 80px, 상 40px / 하 64px. 본문 배경은 `#FFF5EE` 크림(그라데이션은 헤더·포인트에만) — 가독 확보.
  - **포인트 요소**: 콘텐츠 카드는 흰 면 + 반경 20px + 그림자 `0 6px 20px rgba(255,106,136,0.14)`(색 있는 부드러운 그림자).
  - 페이지당 카드 1장만 그라데이션 채움 + 흰 텍스트.
  - 리스트 불릿은 지름 10px 그라데이션 원.
  - 구분선은 직선 대신 완만한 호 1px `#FFD5CC`.
  - 차트는 그라데이션 면 채움(위 진하고 아래 투명하게 페이드).
  - 텍스트 색: 크림 배경 위에서는 `#7A2E45`, 그라데이션 위에서는 흰색 고정.

## ◾ Variation 2: Mint Sky (민트 하늘 · 대각 메쉬)

* **핵심 컬러 (HEX)**: 그라데이션 `#A8EDEA → #7FD8E8 → #6DD5FA`(135° 대각) · 딥 `#0B4F5C` · 화이트 `#FFFFFF` · 액센트 `#FFB84D`(웜 옐로 — 쿨 톤 유일한 대비) · 텍스트 `#0B4F5C`
* **사용 도형 & 그래픽**: **메쉬 그라데이션**(단일 방향이 아니라 여러 색점이 번지는 방식) — 3개 색점을 대각으로 배치해 유기적으로 섞음. 반투명 흰 유리 없이 **불투명 흰 면**만 사용(04번과 구분). 큰 원, 부드러운 물결. V1 수평 → 여기는 **대각 45°**.
* **표지(Cover) 디자인**
  - 배경 메쉬 그라데이션: 좌상단 `#A8EDEA`, 중앙 `#7FD8E8`, 우하단 `#6DD5FA` 3점 블렌드 + 노이즈 5%.
  - **대각 분할 구조** — 좌상단→우하단 방향 -30° 대각선으로 흰색 면이 화면 하단 우측 42%를 덮음(가장자리는 직선, 날카롭게).
  - 제목은 **그라데이션 쪽(좌상단 영역)**에 좌측 정렬, 46pt Semi Bold `#0B4F5C`(흰색 아님 — 밝은 배경이므로 딥톤).
  - 제목 아래 부제 16pt `#0B4F5C` 70%.
  - 흰색 대각 면 안쪽(우하단)에 정보 블록 3개를 세로 나열 — 각각 `#FFB84D` 원형 아이콘 + 라벨 + 수치.
  - 대각 경계선 위에 지름 240px 흰색 원(불투명 40%)이 걸쳐 배치 — 경계를 부드럽게 중화.
  - 좌하단 그라데이션 영역에 발표자·날짜 12pt.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 상단에 흰색 알약 태그(높이 36px, 반경 18px, 불투명 100%) 안 섹션명 `#0B4F5C`. 우측 상단 페이지 숫자 흰색 원 배지.
  - **본문 여백**: 좌우 76px, 상 56px / 하 64px. 배경은 내지에서도 메쉬 그라데이션 유지하되 **불투명도를 낮춘 흰 오버레이 55%**를 깔아 채도 완화.
  - **포인트 요소**: 콘텐츠 카드는 불투명 흰색 + 반경 24px + 그림자 `0 8px 24px rgba(11,79,92,0.10)`.
  - 대각 감각 유지 — 페이지마다 우하단 또는 좌상단에 대각 흰 면 1개 배치(각도 -30° 고정).
  - `#FFB84D`는 아이콘·강조 수치에만.
  - 리스트 불릿은 `#6DD5FA` 원 8px.
  - 차트 색은 그라데이션 3색을 계열로 사용.

## ◾ Variation 3: Lavender Dusk (라벤더 황혼 · 라디얼 광원)

* **핵심 컬러 (HEX)**: 그라데이션 `#C3A0F5 → #9B7BF0 → #7A5FFF` · 딥 배경 `#241B4A` · 하이라이트 `#F0E9FF` · 액센트 `#FF9ECD`(핑크) · 텍스트 `#F0E9FF` / 딥 텍스트 `#2E2159`
* **사용 도형 & 그래픽**: **라디얼(방사형) 그라데이션** — 한 점에서 밖으로 퍼짐. V1 수직 · V2 대각 → 여기는 **중심에서 방사**. 동심원 링, 부드러운 blur 오브, 별점 노이즈. 그라데이션 위에 그라데이션을 겹치는 다중 레이어.
* **표지(Cover) 디자인**
  - 배경 딥 `#241B4A` + 화면 **중앙 약간 아래 지점을 중심**으로 하는 대형 라디얼 그라데이션(중심 `#C3A0F5` → `#9B7BF0` → 외곽 `#7A5FFF` → 딥 배경으로 페이드, 반지름 화면폭 85%) + 노이즈 7%.
  - **중심 집중 동심원 구조** — 그 중심점을 기준으로 1px `#F0E9FF` 동심원 링 3개(반지름 화면폭 25% / 40% / 55%), 불투명도 각 22% / 14% / 8%로 바깥으로 갈수록 옅게.
  - 제목은 라디얼 **중심 정중앙 정렬**, 52pt Light `#F0E9FF`, 자간 +1%, 행간 1.2.
  - 제목 위 24px에 `#FF9ECD` 지름 8px 원 1개 + 좌우로 뻗는 폭 60px 그라데이션 1px 라인(대칭).
  - 제목 아래 32px에 부제 15pt `#C3A0F5`, 중앙 정렬.
  - 화면 네 모서리에 blur 100px 오브 배치: 좌상 `#7A5FFF`, 우하 `#FF9ECD`, 각 불투명 25%.
  - 배경 전면에 1~2px 흰 점 30여 개 산포(불투명 12~35% 랜덤) — 황혼의 별.
  - 하단 중앙에 발표자·날짜 11pt `#C3A0F5`, 자간 +12%.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 중앙에 섹션명 11pt `#C3A0F5` 자간 +18% + 아래 폭 56px 그라데이션 언더라인(`#C3A0F5 → #FF9ECD`).
  - **본문 여백**: 좌우 88px, 상 56px / 하 64px. 배경은 내지에서 라디얼 중심을 **화면 하단 밖으로 이동**시켜 상단이 어둡고 하단이 밝게 — 텍스트 영역 확보.
  - **포인트 요소**: 콘텐츠 카드는 `rgba(240,233,255,0.07)` 면 + 1px `rgba(240,233,255,0.16)` 보더 + 반경 22px.
  - 강조 카드만 배경에 소형 라디얼 그라데이션 채움(`#7A5FFF` 중심).
  - 동심원 링은 내지에서 우측 하단 모서리 기준으로 1/4만 노출(불투명 10%).
  - 강조 수치는 `#C3A0F5 → #FF9ECD` 그라데이션 텍스트 48pt.
  - 리스트 불릿은 지름 8px `#FF9ECD` 원 + 얕은 글로우.
  - 텍스트 순백 금지(`#F0E9FF` 고정). 다크 배경 대비 유지.
