# 16. 인터랙티브 모션 UI (Interactive Motion UI)
> PPT는 정지 매체다. 그래서 이 스타일은 **모션의 흔적**을 정지 화면에 새긴다 — 잔상, 궤적, 진행 상태, 전/후 프레임.
> 실제 애니메이션은 슬라이드 전환 효과로 보조하되, **한 장만 봐도 움직임이 읽혀야** 성립.

**공통 원칙**: 모션 방향은 덱 전체에서 하나로 고정(좌→우 또는 아래→위). 잔상은 3~5단계, 뒤로 갈수록 불투명도 절반씩 감소. 이징 곡선을 그래픽으로 노출. 전환 효과는 실제로 같은 방향으로 설정.

---

## ◾ Variation 1: Kinetic Blue (모션 잔상 · 좌→우 궤적)

* **핵심 컬러 (HEX)**: 배경 `#F4F6FB` · 포인트 `#1B5CFF` · 잔상 `#7FA0FF` / `#B8CBFF` / `#DDE6FF` · 딥 `#0A1F52` · 액센트 `#FF4D4D` · 텍스트 `#0A1F52` / 보조 `#6B7A9E`
* **사용 도형 & 그래픽**: **모션 블러 잔상** — 같은 도형을 3~5개 복제해 좌→우로 어긋나게 배치, 뒤로 갈수록 불투명도 감소(100% → 45% → 22% → 10%). 속도선(speed line), 이징 곡선 그래프, 진행 바. 반경 12px 사각형·정원.
* **표지(Cover) 디자인**
  - 배경 `#F4F6FB`.
  - **좌→우 궤적 구조** — 화면을 가로지르는 수평 모션 축이 콘셉트.
  - 화면 세로 중앙에 지름 120px `#1B5CFF` 원이 **우측 62% 지점**에 위치. 그 왼쪽으로 같은 원의 잔상 4개가 등간격(간격 90px)으로 늘어짐 — 불투명도 45% / 22% / 10% / 4%, 뒤로 갈수록 가로로 늘어나 타원화(속도감).
  - 잔상 궤적 아래를 따라 얇은 2px `#B8CBFF` 수평 트레일 라인이 좌측 끝에서 원까지 이어짐.
  - 제목은 궤적 **위쪽**에 좌측 정렬(좌 여백 88px), 48pt Bold `#0A1F52`. 제목 자체에도 아주 미세한 잔상 1겹(우측으로 6px, `#B8CBFF` 30%) — 활자가 움직이는 느낌.
  - 궤적 아래쪽에 이징 곡선 그래프(`cubic-bezier(0.16,1,0.3,1)` 형태, 2px `#1B5CFF`, 폭 220px) + 옆에 곡선 이름 10pt Courier.
  - 우측 하단에 `#FF4D4D` 원 12px 1개 — 궤적의 도착점 마커.
  - 하단 전폭에 진행 바(트랙 `#DDE6FF` 4px + `#1B5CFF` 필 28%).
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 72px 흰 바. 좌측 섹션명. **하단 경계선이 진행 바** — `#DDE6FF` 3px 트랙 위 `#1B5CFF` 필이 페이지 진행률만큼 채워짐(장마다 실제로 늘어남).
  - **본문 여백**: 좌우 76px, 상 36px / 하 56px.
  - **포인트 요소**: 콘텐츠 카드는 흰 면 + 반경 12px + 그림자 `0 4px 16px rgba(27,92,255,0.10)`. 카드 좌측에 4px `#1B5CFF` 세로 바가 진입 방향 표시.
  - 순서·단계 다이어그램은 반드시 좌→우, 각 단계 사이에 잔상 3겹 화살표.
  - 강조 요소에 미세 잔상 1겹 규칙 적용(우측 4~6px, 30%).
  - 슬라이드 전환은 실제로 **좌→우 밀기(push right)** 로 통일.
  - `#FF4D4D`는 종료·경고 지점에만.

## ◾ Variation 2: Neon Trail (네온 트레일 · 곡선 궤적 · 다크)

* **핵심 컬러 (HEX)**: 배경 `#0D0A14` · 포인트 `#FF2E93`(네온 핑크), 보조 `#00F0FF`(시안) · 트레일 `#8A1A55` → `#3A0A24` · 텍스트 `#F5EFF7` / 보조 `#9A8AA5`
* **사용 도형 & 그래픽**: **긴 곡선 트레일** — 광원이 지나간 자리가 빛으로 남음. 베지어 곡선 스트로크 + 진행 방향으로 굵기가 가늘어지는 테이퍼(tapered) 라인 + 글로우(blur 20px). 파티클 점, 잔광 번짐. V1 직선 잔상 → 여기는 **곡선 광궤**.
* **표지(Cover) 디자인**
  - 배경 `#0D0A14`.
  - **S자 곡선 궤적 구조** — 화면 좌하단에서 시작해 중앙을 크게 휘돌아 우상단으로 빠져나가는 S자 베지어 곡선 1개.
    - 곡선 굵기: 시작 2px → 중간 8px → 끝 3px (테이퍼)
    - 색: 시작 `#3A0A24`(거의 안 보임) → 중간 `#FF2E93` → 끝 `#00F0FF` (진행에 따른 색 전이)
    - 글로우: 곡선 전체에 blur 24px, 불투명 55%
  - 곡선의 **가장 밝은 지점(중앙 우측)** 에 지름 20px 흰색 코어 점 + 그 주변 blur 40px 핑크 광훈.
  - 제목은 곡선이 만든 **빈 공간(좌상단)** 에 좌측 정렬 배치, 50pt Semi Bold `#F5EFF7`. 곡선과 겹치지 않게.
  - 곡선 주변에 파티클 점 20여 개(지름 2~5px, 핑크/시안 혼합, 불투명 20~70%)가 궤적 방향으로 흩날림.
  - 곡선이 지나간 뒤쪽 구간에 잔광 번짐(폭 40px, 불투명 8%)이 곡선을 따라 넓게 퍼짐.
  - 우측 하단에 시안 `[ ▶ ]` 재생 아이콘 + 러닝타임 형식 메타(`00:00 / 24:00`) Courier 11pt.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 전폭에 얇은 트레일 라인(2px, 좌→우 핑크→시안 그라데이션) — 페이지 진행률만큼만 그려지고 끝에 밝은 코어 점. 그 아래 좌측 섹션명 `#9A8AA5`.
  - **본문 여백**: 좌우 80px, 상 48px / 하 60px.
  - **포인트 요소**: 콘텐츠 카드는 `rgba(255,255,255,0.05)` 면 + 1px `rgba(255,46,147,0.28)` 보더 + 반경 16px. 강조 카드만 보더에 네온 글로우.
  - 페이지마다 곡선 트레일 조각 1개가 배경을 지나감 — 슬라이드가 넘어갈수록 곡선의 **다른 구간**이 보이도록 설계(전체 덱이 하나의 긴 궤적).
  - 다이어그램 연결선은 직선 금지, 전부 베지어 곡선 + 방향 끝에 코어 점.
  - 강조 수치는 `#00F0FF` 52pt + 글로우.
  - 슬라이드 전환은 페이드 + 미세 확대(scale 1.02).
  - 텍스트 순백 금지(`#F5EFF7`).

## ◾ Variation 3: Fluid Teal (유체 모션 · 아래→위 상승)

* **핵심 컬러 (HEX)**: 배경 `#F0FDFA` · 포인트 `#00C2A8`(틸) · 유체 `#5EEAD4` / `#99F6E4` / `#CCFBF1` · 딥 `#064E44` · 액센트 `#FFB020` · 텍스트 `#064E44` / 보조 `#4A8B80`
* **사용 도형 & 그래픽**: **유체 파형(wave)** — 서로 다른 주기·진폭의 사인파 3~4겹이 아래에서 위로 밀려 올라옴. 물방울 분리·합체 형태(메타볼), 상승하는 기포 원. V1 수평 · V2 곡선 → 여기는 **수직 상승축**.
* **표지(Cover) 디자인**
  - 배경 `#F0FDFA`.
  - **아래→위 상승 구조** — 화면 하단에서 유체가 차오름.
  - 하단에서부터 파형 레이어 4겹을 쌓음(각각 높이·위상 다름):
    - 1겹(가장 뒤, 가장 높이 차오름 52%): `#CCFBF1`
    - 2겹(44%): `#99F6E4`
    - 3겹(36%): `#5EEAD4`
    - 4겹(가장 앞, 28%): `#00C2A8`
    - 각 파형의 사인 주기를 다르게(1.5 / 2 / 2.5 / 3 주기) 해 겹칠 때 리듬 생성.
  - 유체 위 빈 공간(상단 45%)에 제목 좌측 정렬(좌 여백 92px), 46pt Bold `#064E44`, 하단 정렬 기준으로 유체 표면과 40px 간격.
  - 유체 표면 위로 상승하는 기포 원 8~10개(지름 8~28px, `#00C2A8` 불투명 20~50%) — 위로 갈수록 작고 옅게(상승 감속).
  - 유체 안쪽에 메타볼 형태 물방울 2개가 합쳐지는 순간을 표현(`#00C2A8` 진한 톤).
  - 우측 상단에 `#FFB020` 원 14px + 그 아래로 짧은 수직 점선(하강 대비 요소).
  - 하단 유체 최전면 위에 흰 텍스트로 발표자·날짜 12pt.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 상단에 틸 알약 태그(높이 34px) 안 섹션명 흰 텍스트. 우측 상단에 **세로 진행 인디케이터** — 높이 80px 트랙(`#CCFBF1` 4px) 안에 `#00C2A8` 필이 아래에서 위로 차오름(페이지 진행률).
  - **본문 여백**: 좌우 78px, 상 52px / 하 **96px**(하단 유체 영역 확보).
  - **포인트 요소**: 모든 슬라이드 하단에 파형 2겹 유지(높이 12~16%로 축소) — 표지 규칙 승계, 콘텐츠 가림 방지.
  - 콘텐츠 카드는 흰 면 + 반경 20px + 그림자 `0 6px 18px rgba(0,194,168,0.10)`.
  - 순서·단계 다이어그램은 **아래→위** 방향(V1의 좌→우와 축 분리).
  - 강조 수치는 `#00C2A8` 54pt + 아래에서 위로 페이드되는 그라데이션 채움.
  - 리스트 불릿은 지름 10px 기포 원(속 빈 1.5px 스트로크).
  - `#FFB020`는 하강·감소 지표에만(상승 틸과 대비).
  - 슬라이드 전환은 실제로 **아래에서 위로 밀기(push up)** 로 통일.
