# 07. 3D 및 일러스트레이션 (3D & Illustration)
> 화면의 주인공이 텍스트가 아니라 **오브젝트**. 조명·재질·시점(perspective)이 스타일을 가른다.

**공통 원칙**: 슬라이드마다 오브젝트는 1~3개까지. 조명 방향은 덱 전체에서 고정. 오브젝트 아래 접지 그림자(contact shadow)를 반드시 넣어 떠 있는 느낌 방지.

---

## ◾ Variation 1: Clay Pop (클레이 3D · 무광 파스텔)

* **핵심 컬러 (HEX)**: 배경 `#FFF1E9` · 오브젝트 `#FF8A5B`(메인), `#FFC9A3`(라이트), `#5B4A42`(딥 섀도) · 보조 오브젝트 `#7BD3C4` · 텍스트 `#3D2B23` / 보조 `#8A7266`
* **사용 도형 & 그래픽**: **무광 점토(clay) 렌더** — 모서리를 크게 굴린 뭉툭한 도넛·구·캡슐·물결 리본. 반사광 없음, 부드러운 SSS(피부 투과) 느낌. 그림자는 blur 40px 이상 아주 물렁하게. 재질은 미세 벨벳 노이즈 5%.
* **표지(Cover) 디자인**
  - 배경 `#FFF1E9` 단색 + 화면 하단 중앙에 폭 70% 타원형 `#FFE0CE` 접지 그림자 면.
  - **좌측 텍스트 : 우측 오브젝트 (45:55) 구조**.
  - 우측에 클레이 오브젝트 군집: 지름 380px 뭉툭한 도넛(`#FF8A5B`)이 중심, 그 뒤로 지름 180px 구(`#7BD3C4`)가 반쯤 가려짐, 앞쪽에 캡슐 2개(`#FFC9A3`)가 바닥에 눕혀짐.
  - 오브젝트는 **약간 위에서 내려다본 시점(15° 하향)**, 조명은 좌상단 30°.
  - 좌측 텍스트 영역: 제목 46pt ExtraBold `#3D2B23`, 좌측 정렬, 하단 정렬 기준. 제목 위에 라운드 알약 태그(`#FF8A5B` 배경, 흰 텍스트, 반경 20px).
  - 제목 뒤로 오브젝트가 8% 정도 겹쳐 들어오게 배치 — 평면/입체 층위 교차.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 상단 알약 태그(`#FFE0CE` 배경, `#3D2B23` 텍스트, 높이 34px) 안 섹션명. 우측 상단에 지름 36px 클레이 구 하나 위에 페이지 숫자.
  - **본문 여백**: 좌우 76px, 상 52px / 하 64px.
  - **포인트 요소**: 콘텐츠 카드는 반경 32px 초라운드, 배경 `#FFFFFF`, 그림자 `0 12px 32px rgba(255,138,91,0.16)`(색 있는 물렁 그림자).
  - 각 카드 우측 상단에 지름 56px 클레이 아이콘 오브젝트가 카드 밖으로 40% 튀어나옴 — 3D가 2D 카드를 뚫는 연출.
  - 리스트 불릿은 지름 14px 클레이 구.
  - 배경 여백에 저채도 클레이 오브젝트 1개를 불투명 20%로 흐리게 깔아 깊이 부여(포커스 밖 처리).

## ◾ Variation 2: Isometric Blue (아이소메트릭 · 테크 구조도)

* **핵심 컬러 (HEX)**: 배경 `#EEF1FB` · 메인 `#4F6BED` · 면 3단계 `#7A90F5`(윗면) / `#4F6BED`(좌면) / `#3A4FBF`(우면) · 액센트 `#FFB020` · 텍스트 `#1B2559` / 보조 `#6B76A8`
* **사용 도형 & 그래픽**: **정확한 30° 아이소메트릭** 큐브·플레이트·계단·레이어 스택. 원근 없음(평행 투영). 면마다 명도 3단계 고정 — 이것만으로 입체 성립. 그림자는 blur 8px 짧고 딱딱하게(V1의 물렁함과 정반대). 얇은 `#FFB020` 연결선·노드로 흐름 표시.
* **표지(Cover) 디자인**
  - 배경 `#EEF1FB` + 30° 아이소메트릭 격자 라인(`#D5DCF5` 1px, 간격 48px)을 전면에 6% 불투명으로 깔기.
  - **중앙 하단 집중 구조** — 화면 하단 중앙에 아이소메트릭 **레이어 스택**(가로 폭 화면 52%) 3~4단을 쌓아 올림. 아래층이 가장 넓고 위로 갈수록 좁아짐.
  - 각 층 사이 간격 24px에 `#FFB020` 세로 연결 기둥 + 노드 점.
  - 제목은 스택 **위쪽 빈 공간 중앙 정렬**, 42pt Bold `#1B2559`. 스택 최상단 층과 32px 간격.
  - 좌우 하단 구석에 작은 아이소메트릭 큐브 1개씩(지름 60px 수준) 흩어 배치, 불투명 50%.
  - 접지 그림자는 각 오브젝트 바닥에 30° 마름모꼴로 `#C9D2F0` 채움.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 72px `#4F6BED` 풀블리드 바 + 흰 텍스트 섹션명. 우측에 `#FFB020` 진행 도트 배열.
  - **본문 여백**: 좌우 72px, 상 32px / 하 56px.
  - **포인트 요소**: 다이어그램은 전부 아이소메트릭 큐브 노드 + 30° 각도 연결선으로 작도 — 일반 화살표 금지, 반드시 30°/150° 각도만 사용.
  - 콘텐츠 카드는 평면(반경 12px, 흰색)이되, 카드 좌측에 아이소메트릭 큐브 아이콘 64px 배치.
  - 배경 아이소 격자를 내지에서도 4% 유지.
  - 데이터 시각화는 3D 막대(윗면·좌면·우면 3톤)로 표현.

## ◾ Variation 3: Glossy Candy (유광 3D · 다크 무대)

* **핵심 컬러 (HEX)**: 배경 `#160C24`(딥 퍼플 블랙) · 메인 `#B14EFF` · 보조 `#FF4ECD`, `#4EE0FF` · 하이라이트 `#FFFFFF` · 텍스트 `#F4EAFF` / 보조 `#A48CC4`
* **사용 도형 & 그래픽**: **하이글로스 유광 렌더** — 크롬/젤리 재질의 구, 꼬인 리본(twisted torus), 액체 방울. 각 오브젝트에 흰색 스펙큘러 하이라이트 점 + 림라이트(rim light) 필수. 배경에 컬러 스포트라이트. V1 무광·V2 평행투영과 완전 대비되는 **강한 원근(perspective 45°)**.
* **표지(Cover) 디자인**
  - 배경 `#160C24` + 화면 중앙 뒤에서 퍼지는 라디얼 스포트라이트(`#B14EFF` 22% → 투명, 반지름 화면폭 70%) — 오브젝트 뒤 광원.
  - **정중앙 단일 히어로 오브젝트 구조**(V1 우측군집·V2 하단스택과 분리).
  - 화면 정중앙에 꼬인 리본 형태 유광 오브젝트(높이 화면 56%)를 크게 배치. 표면에 `#B14EFF → #FF4ECD → #4EE0FF` 홀로그래픽 그라데이션 반사.
  - 제목은 그 오브젝트 **앞을 가로지르며** 중앙 정렬 배치, 58pt Bold `#F4EAFF`. 텍스트 일부가 오브젝트에 가려지는 레이어링(텍스트 뒤 오브젝트 일부 → 앞 오브젝트 일부).
  - 오브젝트 주변에 지름 12~24px 유광 구슬 5~6개를 원근감 있게 흩뿌림(가까운 것은 blur 처리 = 피사계심도).
  - 바닥에 반사(reflection) 30% + 아래로 페이드.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 중앙에 섹션명 11pt `#A48CC4` 자간 +16%, 아래 폭 48px 홀로그래픽 그라데이션 라인.
  - **본문 여백**: 좌우 84px, 상 56px / 하 64px.
  - **포인트 요소**: 콘텐츠 카드는 반투명 다크(`rgba(255,255,255,0.06)`) + 1px `rgba(255,255,255,0.14)` 보더 + 반경 24px — 오브젝트가 주인공이므로 카드는 물러남.
  - 슬라이드마다 유광 오브젝트 1개를 우측 또는 좌측 여백에 배치하되 **크기를 표지의 40% 이하**로 축소.
  - 강조 텍스트는 홀로그래픽 그라데이션 채움.
  - 피사계심도 규칙: 전경 오브젝트만 선명, 배경 오브젝트는 blur 12px.
  - 금지: 오브젝트 3개 초과, 스포트라이트 2개 이상.
