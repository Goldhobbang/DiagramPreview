# PPT 템플릿 60종 디자인 기획 — 전체 개요

20가지 UI/UX 스타일 × 3 베리에이션 = 60개 템플릿. 각 베리에이션은 표지(Cover)와 전역/내지(Global) 디자인 가이드를 포함한다.

## 파일 구조
```
00_GUIDES/PLANS/
├── 00_OVERVIEW.md          ← 이 문서 (전체 요약표 + 진행 현황)
├── 01_FLAT_DESIGN.md
├── 02_MINIMALISM.md
├── 03_DARK_MODE.md
└── ... (스타일당 1파일, 총 20개)
```

## 차별화 원칙
- 스타일 내 3종은 **메인 컬러 계열**(쿨/웜/뉴트럴 또는 라이트/다크)과 **화면 분할 구조**(수직분할 / 수평·곡선분할 / 중앙집중 등)를 서로 다르게 배정.
- 60개 전체에서 동일 HEX 중복 금지.
