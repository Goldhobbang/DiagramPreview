# 20. 스토리텔링형 스크롤 UI (Storytelling Scroll UI)
> 웹의 스크롤 서사를 슬라이드로 옮긴다. 각 장이 독립된 페이지가 아니라 **하나의 긴 흐름을 잘라낸 프레임**.
> 16번 모션 UI와 구분: 거기는 **개별 요소의 움직임**, 여기는 **덱 전체를 관통하는 서사 축과 진행 좌표**.

**공통 원칙**: 덱 전체에 하나의 연속 축(세로선·경로·타임라인)이 있고, 각 슬라이드는 그 축의 **다른 구간**을 보여준다. 슬라이드마다 현재 위치 인디케이터 필수. 앞장의 마지막 요소가 다음 장 첫 요소로 이어지게(모티프 승계).

---

## ◾ Variation 1: Journey Indigo (여정 · 세로 타임라인 축)

* **핵심 컬러 (HEX)**: 배경 `#F7F7FB` · 딥 `#312E81`(인디고) · 축 `#A5A3D9` · 액센트 `#F59E0B`(앰버) · 면 `#FFFFFF` · 텍스트 `#1E1B4B` / 보조 `#6B68A8`
* **사용 도형 & 그래픽**: **세로 타임라인 축** — 화면 좌측 26% 지점을 관통하는 2px 세로선. 축 위 노드 원(지난 노드=채움, 현재=큰 링, 미래=속 빈 원), 축에서 우측으로 뻗는 가지선. 챕터 진행 게이지.
* **표지(Cover) 디자인**
  - 배경 `#F7F7FB`.
  - **세로 축 시작점 구조** — 축이 화면 상단에서 시작해 아래로 흐르는 첫 프레임.
  - 좌측 26% 지점에 2px `#312E81` 세로선이 화면 **상단 40% 지점에서 시작**해 아래 끝까지(시작점이 보이는 것이 표지 표시).
  - 축 시작점에 지름 28px `#312E81` 채움 원 + 그 둘레에 지름 56px `#A5A3D9` 링(불투명 40%).
  - 축을 따라 아래로 노드 4개(지름 12px, 속 빈 `#A5A3D9` 원, 간격 균등) — 앞으로 나올 챕터 예고.
  - 제목은 축 **우측**에 좌측 정렬(축에서 48px 간격), 시작점 노드와 같은 높이, 46pt Bold `#1E1B4B`, 행간 1.12.
  - 제목 위에 `#F59E0B` 알약 태그(높이 30px) — 카테고리.
  - 제목 아래 부제 16pt `#6B68A8`, 폭 화면 44% 제한.
  - 축 좌측 여백(26% 영역)에는 세로쓰기 연도 10pt `#A5A3D9`, 자간 +30%.
  - 우측 하단에 흰 카드(반경 16px, 그림자 얕게) 1장 — 목차 미리보기 4줄, 각 줄 앞에 축의 노드 색과 대응하는 작은 원.
  - 화면 하단 가장자리에 축이 **잘리지 않고 밖으로 계속 이어짐**(다음 장으로 연결됨을 암시).
* **전역(Global) 디자인**
  - **상단 헤더**: 헤더 바 없음. 대신 **좌측 세로 축이 전 페이지 유지** — 현재 챕터 노드만 지름 24px `#312E81` 채움 + 링, 지난 노드는 `#A5A3D9` 채움, 미래 노드는 속 빈 원.
  - 축 상단 끝에 이전 페이지에서 이어진 선이 **화면 밖에서 들어옴**(잘린 형태) — 연속성 장치.
  - **본문 여백**: 축 우측 48px부터 콘텐츠, 우 72px, 상 56px / 하 64px.
  - **포인트 요소**: 각 콘텐츠 블록은 축의 노드에서 뻗어 나온 가지선(1px `#A5A3D9`, 직각 꺾임)으로 축과 연결.
  - 카드는 흰 면 + 반경 16px + 그림자 `0 2px 12px rgba(49,46,129,0.08)`.
  - 현재 챕터명은 축 좌측 여백에 세로쓰기로 상시 표기.
  - `#F59E0B`는 현재 위치·핵심 전환점에만.
  - 슬라이드 하단에 진행 게이지(폭 화면 26%, 좌측 정렬, 2px 트랙 + 인디고 필).

## ◾ Variation 2: Nature Path (자연 · 곡선 경로 · 지도형)

* **핵심 컬러 (HEX)**: 배경 `#F3F7F0` · 딥 `#2F6B4F`(포레스트 그린) · 경로 `#B8CFB0` · 액센트 `#D97706`(단풍 오렌지) · 면 `#FFFFFF` · 텍스트 `#1F3D2E` / 보조 `#63856F`
* **사용 도형 & 그래픽**: **곡선 등산로 경로** — 부드러운 베지어 곡선이 화면을 가로지름(V1 직선축과 분리). 지형 등고선, 지도 핀 마커, 거리 표기, 유기적 잎·언덕 실루엣. 손그림 질감의 점선 경로.
* **표지(Cover) 디자인**
  - 배경 `#F3F7F0` + 아주 옅은 등고선 패턴(1px `#DCE8D6`, 불규칙 동심 곡선, 불투명 45%).
  - **곡선 경로 시작점 구조** — 화면 좌하단에서 시작해 완만한 S자로 우상단을 향하는 경로.
    - 경로: 3px `#2F6B4F` 실선 + 그 위에 4px on / 8px off 점선 `#B8CFB0` 겹침(등산로 표기 관습)
    - 경로 시작점(좌하단)에 지도 핀 마커(높이 44px, `#D97706` 채움 + 흰 원 코어)
    - 경로 위 중간 지점 3곳에 작은 원 노드(지름 14px, 흰 채움 + 2px `#2F6B4F` 보더)
    - 경로 끝(우상단)은 화면 밖으로 빠져나감
  - 제목은 경로가 비워 둔 **좌상단~중앙 공간**에 좌측 정렬(좌 여백 88px), 44pt Semi Bold `#1F3D2E`.
  - 제목 아래 부제 16pt `#63856F`.
  - 경로 시작 핀 옆에 `START` 라벨 + 날짜 11pt.
  - 화면 하단·우측 가장자리에 언덕 실루엣 2겹(`#DCE8D6` / `#B8CFB0`, 불투명 60% / 100%)이 완만하게 겹침.
  - 좌상단 구석에 잎 실루엣 1개(`#B8CFB0`, 불투명 50%), 우하단에 작게 1개.
  - 우측 상단에 총 구간 표기 — `24 STEPS` 형식, 대문자 자간 +20% `#63856F`.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 전폭에 경로 곡선 조각(3px + 점선)이 좌→우로 흐름. 현재 위치에 `#D97706` 핀 마커 1개가 곡선 위에 꽂힘 — 페이지가 넘어갈수록 핀이 우측으로 이동(진행 표시).
  - 곡선 좌측 끝은 화면 밖에서 들어오고 우측 끝은 밖으로 나감 — 연속성.
  - **본문 여백**: 좌우 76px, 상 **88px**(헤더 곡선 영역), 하 64px.
  - **포인트 요소**: 콘텐츠 카드는 흰 면 + 반경 20px + 그림자 `0 4px 16px rgba(47,107,79,0.08)`.
  - 단계·순서 다이어그램은 직선 화살표 금지 — 반드시 곡선 경로 + 노드로 작도.
  - 등고선 패턴 배경에 상시 유지(불투명 30%).
  - 리스트 불릿은 작은 잎 아이콘 12px 또는 `#2F6B4F` 원 8px.
  - `#D97706`는 현재 위치·전환점에만, 페이지당 1회.
  - 강조 수치는 `#2F6B4F` 52pt, 아래 캡션에 단위·거리 표기 스타일.
  - 챕터 전환 슬라이드는 언덕 실루엣을 크게 키워 전체 화면의 40%까지 — 능선을 넘는 감각.

## ◾ Variation 3: Cosmic Scroll (우주 · 수평 궤도 · 다크)

* **핵심 컬러 (HEX)**: 배경 `#0B0B2B` · 딥 `#05051A` · 궤도 `#3A3A7A` · 포인트 `#FFD166`(별빛 골드), 보조 `#7B9FFF`(블루) · 텍스트 `#EDEDF7` / 보조 `#9A9AC4`
* **사용 도형 & 그래픽**: **수평 궤도 축**(V1 세로 · V2 곡선 → 여기는 가로) — 화면을 좌에서 우로 관통하는 타원 궤도선. 행성 원, 궤도 링, 별 점, 성운 blur. 각 챕터 = 하나의 행성.
* **표지(Cover) 디자인**
  - 배경 `#0B0B2B` + 화면 우상단에서 퍼지는 성운 blur 오브(`#3A3A7A` 불투명 30%, blur 140px) + 별 점 60여 개(1~3px 흰색, 불투명 15~70% 랜덤, 일부는 `#FFD166`).
  - **수평 궤도 구조** — 화면 세로 62% 지점을 좌에서 우로 가로지르는 아주 완만한 타원 궤도선(1.5px `#3A3A7A`, 양끝 화면 밖으로).
  - 궤도 위 좌측 28% 지점에 **주 행성**(지름 200px): 채움은 `#7B9FFF → #3A3A7A` 좌상 라디얼 그라데이션, 좌상단에 흰색 하이라이트, 우하단은 그림자로 어둡게. 행성 둘레에 기울어진 링 1개(1.5px `#FFD166`, 불투명 60%, -18° 기울임).
  - 궤도 위 우측으로 작은 행성 4개(지름 32 / 24 / 20 / 16px, 오른쪽으로 갈수록 작고 어둡게 — 원근) — 앞으로 나올 챕터.
  - 제목은 궤도 **위쪽 영역**, 주 행성 우측에 좌측 정렬, 48pt Light `#EDEDF7`, 자간 +1%.
  - 제목 위에 `#FFD166` 지름 6px 원 + 카테고리 라벨 11pt 자간 +24%.
  - 제목 아래 부제 15pt `#9A9AC4`.
  - 궤도선 아래 좌측에 발표자·날짜 11pt `#9A9AC4`.
  - 우측 하단에 좌표 형식 메타(`CH.01 / 24` Courier 10pt `#7B9FFF`).
* **전역(Global) 디자인**
  - **상단 헤더**: 헤더 바 없음. **수평 궤도선을 전 페이지 상단 18% 지점에 유지** — 현재 챕터 행성만 지름 40px로 크게 + `#FFD166` 링, 지난 행성은 `#3A3A7A` 어둡게, 미래 행성은 속 빈 원.
  - 궤도선은 좌우 화면 밖으로 이어짐. 페이지가 넘어갈수록 궤도가 **좌측으로 이동**해 다음 행성이 중앙에 옴.
  - **본문 여백**: 좌우 82px, 상 **136px**(궤도 영역 확보), 하 60px.
  - **포인트 요소**: 콘텐츠 카드는 `rgba(237,237,247,0.05)` 면 + 1px `rgba(123,159,255,0.22)` 보더 + 반경 18px.
  - 강조 카드만 보더 `#FFD166` + 얕은 글로우.
  - 챕터 전환 슬라이드는 해당 행성을 화면 중앙에 지름 320px로 확대 — 궤도에서 줌인하는 감각.
  - 별 점 배경 전 페이지 유지(내지에서는 불투명 절반).
  - 리스트 불릿은 지름 6px `#FFD166` 원 + 미세 글로우.
  - 강조 수치는 `#FFD166` 54pt Light.
  - 연결선·다이어그램은 궤도와 같은 타원 곡선 어휘로 통일.
  - 텍스트 순백 금지(`#EDEDF7`).
