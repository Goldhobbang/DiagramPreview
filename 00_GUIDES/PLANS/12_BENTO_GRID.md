# 12. 벤토 그리드 (Bento Grid)
> 도시락 칸처럼 **크기가 다른 셀이 빈틈없이 맞물린 격자**. 카드 기반(06번)과 구분: 벤토는 셀 사이 여백이 균일하고 **전체가 하나의 직사각형으로 딱 떨어져야** 한다.

**공통 원칙**: 기준 그리드 6열 × 4행. 셀 크기는 그 배수로만(1×1 / 2×1 / 2×2 / 3×2 / 4×2). 거터 전 방향 균일(16~24px). 남는 빈칸 금지 — 반드시 채우거나 셀을 키운다. 셀 하나 = 정보 하나.

---

## ◾ Variation 1: Light Bento (라이트 · 애플식 정갈)

* **핵심 컬러 (HEX)**: 배경 `#F2F2F7` · 셀 `#FFFFFF` · 포인트 `#0A84FF`, 보조 `#FF9F0A`(앰버) · 텍스트 `#1C1C1E` / 보조 `#6E6E73` · 구분 `#E5E5EA`
* **사용 도형 & 그래픽**: 반경 20px 셀, 그림자 없음(배경 명도차로만 분리), 셀 안에 대형 SF Symbol풍 아이콘·미니 차트·숫자. 그라데이션은 강조 셀 하나에만(`#0A84FF → #5AC8FA` 135°). 거터 20px 균일.
* **표지(Cover) 디자인**
  - 배경 `#F2F2F7`. 화면 여백 상하좌우 56px 안에 **6×4 벤토 격자**를 꽉 채움.
  - 셀 배치(6열 4행 기준):
    - **3×2 (좌상단)**: 제목 셀. 흰 배경. 제목 좌측 정렬 하단 기준, 40pt Bold `#1C1C1E`. 위에 `#0A84FF` 알약 태그.
    - **3×2 (우상단)**: `#0A84FF → #5AC8FA` 그라데이션 셀. 흰 텍스트로 핵심 한 줄 + 우하단 대형 아이콘(불투명 25%).
    - **2×2 (좌하단)**: 흰 셀 + 대형 숫자 지표(64pt `#0A84FF`) + 라벨.
    - **2×2 (중앙하단)**: 흰 셀 + 미니 라인 차트(`#0A84FF` 2px + 하단 페이드 채움).
    - **1×1 ×2 (우하단 상부)**: 아이콘 셀 2개, `#FF9F0A` 아이콘.
    - **2×1 (우하단)**: 발표자·날짜 셀, `#6E6E73` 13pt.
  - 격자 밖 요소 **전무** — 모든 정보가 셀 안에.
* **전역(Global) 디자인**
  - **상단 헤더**: 격자 위에 별도 헤더 바 없음. 대신 **좌상단 1×1 셀을 헤더 셀로 고정** — 안에 섹션명 12pt + 하단에 페이지 `03/24`.
  - **본문 여백**: 상하좌우 56px, 거터 20px. 6×4 격자 유지.
  - **포인트 요소**: 페이지당 그라데이션 강조 셀 **1개만**. 나머지 흰색.
  - 셀 내부 패딩 24px 고정. 텍스트는 셀 좌상단, 아이콘·그래픽은 우하단 정렬이 기본 규칙.
  - 아이콘 크기 32px(1×1) / 48px(2×2) / 72px(3×2)로 셀 크기에 비례.
  - 이미지 셀은 반경 20px 마스크 + 풀블리드(패딩 0).
  - 금지: 셀 겹침, 셀 회전, 빈칸.

## ◾ Variation 2: Dark Bento (다크 · 대시보드 밀도)

* **핵심 컬러 (HEX)**: 배경 `#101012` · 셀 `#18181B` / 상위 셀 `#232327` · 보더 `#2E2E33` · 포인트 `#30D158`(그린), 보조 `#BF5AF2`(퍼플), 경고 `#FF453A` · 텍스트 `#F4F4F5` / 보조 `#8E8E93`
* **사용 도형 & 그래픽**: 반경 16px 셀 + 1px `#2E2E33` 보더(다크에서는 명도차만으로 부족). 셀 안에 실시간 대시보드 요소 — 스파크라인, 게이지 링, 히트맵 도트, 진행 바. 포인트 컬러에만 얕은 글로우(blur 16px, 25%). V1보다 **셀 개수 많고 밀도 높음**(6×4 → 실질 8~10셀).
* **표지(Cover) 디자인**
  - 배경 `#101012`. 여백 48px, 거터 16px — V1보다 촘촘.
  - **좌우 비대칭 벤토**(V1 균형 배치와 분리): 좌측 4열은 큰 셀 위주, 우측 2열은 작은 셀 세로 스택.
    - **4×3 (좌측 대형)**: 제목 셀. `#18181B`. 제목 좌측 정렬, 48pt Bold `#F4F4F5`. 배경에 `#30D158` 히트맵 도트 그리드(불투명 12%)가 셀 우하단에서 페이드.
    - **2×1 ×3 (우측 상단부터)**: 지표 셀 3개 세로 스택. 각각 라벨 11pt `#8E8E93` + 수치 28pt + 스파크라인.
      - 셀1 그린 `#30D158` / 셀2 퍼플 `#BF5AF2` / 셀3 레드 `#FF453A`
    - **2×1 (좌하단)**: 게이지 링 셀 — 원형 진행 링(`#30D158`, 두께 8px) + 중앙 퍼센트.
    - **2×1 (중앙하단)**: 발표자·날짜.
    - **2×1 (우하단)**: `#BF5AF2` 그라데이션 셀 + 화살표 아이콘 — CTA 성격.
  - 셀 하나(우하단)만 배경 `#232327`로 한 단계 밝게 = 시선 앵커.
* **전역(Global) 디자인**
  - **상단 헤더**: 전폭 얇은 바(높이 52px, 배경 `#101012`, 하단 1px `#2E2E33`) — 격자 위 별도 레이어. 좌측 섹션명 `#8E8E93`, 우측 그린 도트 + `03/24`.
  - **본문 여백**: 좌우 48px, 상 20px / 하 48px. 거터 16px.
  - **포인트 요소**: 셀 명도 2단계만(`#18181B` 기본 / `#232327` 강조), 3단 금지.
  - 모든 수치 셀은 좌상단 라벨 → 중앙 대형 수치 → 하단 스파크라인 3단 구조 통일.
  - 컬러는 의미 고정: 그린=긍정/현재, 퍼플=중립/예측, 레드=경고.
  - 셀 내부 패딩 20px.
  - 차트 격자선은 `#2E2E33` 1px, 라벨 10pt `#8E8E93`.
  - 텍스트 순백 금지(`#F4F4F5`).

## ◾ Variation 3: Warm Bento (웜 · 매거진 에디토리얼)

* **핵심 컬러 (HEX)**: 배경 `#FFF7ED` · 셀 `#FFFFFF` / 틴트 셀 `#FFEDD5` · 포인트 `#EA580C`(테라코타 오렌지), 보조 `#166534`(딥그린), `#78350F`(브라운) · 텍스트 `#431407` / 보조 `#9A6B4F`
* **사용 도형 & 그래픽**: 반경 **28px 큰 라운드** + 셀마다 반경을 다르게(일부는 `28px 28px 4px 28px` 비대칭). 세리프 타이포 중심. 셀 안에 사진·일러스트 비중 높음. 얇은 `#EA580C` 1px 아웃라인 셀 1~2개 혼용. V1 정갈·V2 밀도 → 여기는 **에디토리얼 리듬**.
* **표지(Cover) 디자인**
  - 배경 `#FFF7ED`. 여백 60px, 거터 24px — 가장 넉넉.
  - **큰 셀 소수 + 세리프 대형 타이포 구조**.
    - **4×4 (좌측 전체 높이)**: 이미지 셀. 풀블리드 사진, 반경 28px, 하단 40%에 `#431407` → 투명 그라데이션 오버레이.
    - **2×2 (우상단)**: 제목 셀. 흰 배경. 제목 세리프 38pt `#431407`, 좌측 정렬. 제목 위에 `#EA580C` 짧은 2px 수평선.
    - **2×1 (우측 중단)**: `#FFEDD5` 틴트 셀 — 부제 또는 인용문, 세리프 이탤릭 16pt.
    - **1×1 (우하단 좌)**: `#166534` 채움 셀 + 흰 아이콘.
    - **1×1 (우하단 우)**: `#EA580C` 1px 아웃라인만 있는 투명 셀 + 날짜 세리프.
  - 좌측 이미지 셀 위에 카테고리 라벨(흰 텍스트, 대문자, 자간 +20%)을 좌상단에 얹음.
  - 셀 반경을 전부 같게 두지 않고 이미지 셀만 `28px`, 나머지 `20px`로 미세 차등.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌상단 2×1 셀을 헤더 셀로 사용 — `#FFEDD5` 틴트, 안에 섹션명 세리프 + 우측 페이지 숫자. V1(1×1 헤더셀) 규칙의 웜 버전.
  - **본문 여백**: 상하좌우 60px, 거터 24px.
  - **포인트 요소**: 텍스트 셀은 세리프 본문(16pt, 행간 1.7), 제목만 세리프 Bold — 매거진 조판 감각.
  - 페이지마다 이미지 셀 최소 1개 필수(에디토리얼 정체성).
  - 틴트 셀 `#FFEDD5`는 인용·요약 전용.
  - 아웃라인 셀(채움 없음, 1px `#EA580C`)은 페이지당 1개 — 여백처럼 작동하되 격자는 유지.
  - 리스트 불릿은 `#EA580C` 세리프 대시(–).
  - 강조 수치는 세리프 60pt `#EA580C`, 아래 브라운 캡션.
