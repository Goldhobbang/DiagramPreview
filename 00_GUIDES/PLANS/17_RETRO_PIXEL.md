# 17. 레트로 및 픽셀 아트 (Retro & Pixel Art)
> 저해상도 격자가 미학이 된다. **픽셀은 반드시 정수 배수로만 확대** — 0.5px, 안티에일리어싱, 라운드 반경은 이 스타일을 즉시 죽인다.

**공통 원칙**: 기준 픽셀 단위 4px(모든 크기·간격은 4의 배수). 반경 0. 안티에일리어싱 OFF(`image-rendering: pixelated`). 서체는 비트맵 픽셀 폰트(Press Start 2P / DungGeunMo / Galmuri). 팔레트 색 수 제한 — 많을수록 레트로 아님.

---

## ◾ Variation 1: Arcade CRT (아케이드 · CRT 스캔라인)

* **핵심 컬러 (HEX)**: 배경 `#1A1A2E`(딥 네이비) · 포인트 `#00FF9F`(포스포 그린), 보조 `#FF3864`(레드), `#FFD23F`(옐로), `#3AC8FF`(시안) · 딥 `#0A0A18` · 텍스트 `#EAEAF5`
* **팔레트 제한**: 6색 고정.
* **사용 도형 & 그래픽**: 8×8 / 16×16 픽셀 스프라이트, 계단식 대각선(anti-alias 없는 픽셀 계단), 2px 픽셀 보더, 도트 패턴. **CRT 효과 3종**: 스캔라인(2px 간격 검정 10%), 화면 모서리 배럴 왜곡(가장자리 비네트 20%), RGB 색분리(빨강 -1px / 파랑 +1px 미세 밀림).
* **표지(Cover) 디자인**
  - 배경 `#1A1A2E` + 스캔라인 + 비네트.
  - **아케이드 타이틀 화면 구조** — 위에서 아래로 정보가 쌓이는 세로 중앙 정렬.
    1. 상단 여백 후 픽셀 스프라이트 1개(48×48 확대, 예: 캐릭터·아이콘) 중앙 배치, 좌우로 8px씩 흔들린 잔상 없음(정지)
    2. 제목: 픽셀 폰트 56pt `#00FF9F`, 중앙 정렬. **각 글자에 4px 오프셋 `#FF3864` 하드 섀도**(우하 방향) — 아케이드 로고 관습
    3. 제목 아래 32px에 2px `#3AC8FF` 픽셀 수평선(점선 아님, 실선), 폭 화면 60%
    4. 그 아래 `PRESS START` 형식 부제 픽셀 폰트 14pt `#FFD23F` — 깜빡임 표현은 불투명 100% 고정
    5. 하단에 `1UP  000000    HI-SCORE  999999` 형식 메타 정보(발표자·날짜를 이 포맷에 대입) 10pt `#EAEAF5`
  - 화면 네 모서리 안쪽 16px 지점에 픽셀 코너 브래킷(ㄱ자, 2px, `#00FF9F`).
  - 하단 전폭에 픽셀 지면 타일(높이 32px, 8px 격자 패턴 `#0A0A18` / `#252540` 교대).
  - RGB 색분리는 제목에만 적용.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 48px `#0A0A18` 바 + 하단 2px `#00FF9F` 픽셀 선. 좌측 섹션명 픽셀 폰트 12pt `#00FF9F`, 우측 `STAGE 03/24`.
  - **본문 여백**: 좌우 64px(16의 배수), 상 32px / 하 48px. 모든 간격 8px 배수 강제.
  - **포인트 요소**: 콘텐츠 박스는 **픽셀 다이얼로그 창** — 2px `#EAEAF5` 외곽선 + 안쪽 2px `#3AC8FF` 선, 사이 4px 간격, 배경 `#0A0A18`. 반경 0.
  - 리스트 불릿은 8×8 픽셀 하트 또는 정사각형.
  - 진행 표시는 픽셀 HP 바 — 트랙 `#252540` + 필 `#00FF9F`, 셀 단위로 끊김(연속 아님).
  - 강조 수치는 픽셀 폰트 40pt `#FFD23F` + 4px `#FF3864` 하드 섀도.
  - 이미지는 **의도적 저해상도 변환**(원본 → 64px 폭 축소 → 정수배 확대) + 6색 팔레트 디더링.
  - 스캔라인·비네트 전 페이지 유지.

## ◾ Variation 2: Gameboy Olive (4색 모노 · 도트 매트릭스)

* **핵심 컬러 (HEX)**: 배경(가장 밝음) `#9BBC0F` · 밝은 중간 `#8BAC0F` · 어두운 중간 `#306230` · 가장 어두움 `#0F380F` · 텍스트 `#0F380F`
* **팔레트 제한**: **4색 전부**. 다섯 번째 색 금지 — 이 제약이 정체성.
* **사용 도형 & 그래픽**: 4색만으로 명암을 만들어야 하므로 **디더링 패턴**이 핵심(체커보드 50% / 25% 도트로 중간톤 생성). 도트 매트릭스 격자(1px 간격 어두운 선, 불투명 12%)로 LCD 픽셀 느낌. V1 CRT(발광·컬러) → 여기는 **비발광·저대비 LCD**.
* **표지(Cover) 디자인**
  - 배경 `#9BBC0F` 전면 + 도트 매트릭스 격자 오버레이.
  - **좌우 2분할 카트리지 구조**(V1 세로중앙과 분리).
    - 좌측 42%: `#0F380F` 단색 면. 그 안에 32×32 픽셀 스프라이트 3개를 세로로 배열(`#9BBC0F` 채움) — 목차 아이콘.
    - 우측 58%: `#9BBC0F` 유지. 제목 좌측 정렬, 픽셀 폰트 44pt `#0F380F`, 행간 1.4(픽셀 폰트는 행간 넉넉해야 읽힘).
  - 좌우 경계는 직선이 아니라 **8px 픽셀 계단**으로 처리(3~4단 들쭉날쭉).
  - 제목 아래 24px에 `#306230` 2px 선 + 그 아래 부제 픽셀 폰트 14pt `#306230`.
  - 우측 하단에 디더링 25% 패턴으로 채운 사각형(가로 30% × 세로 18%) + 그 위 발표자·날짜 10pt.
  - 화면 전체 테두리에 4px `#0F380F` 픽셀 프레임(카트리지 라벨 느낌).
  - 우측 상단에 `#306230` 배터리 아이콘 픽셀 스프라이트 1개.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 40px `#0F380F` 바 + 우측 끝 8px 픽셀 계단 마감. 좌측 섹션명 `#9BBC0F` 11pt, 우측 `03/24`.
  - **본문 여백**: 좌우 56px, 상 28px / 하 40px. 4px 배수 강제.
  - **포인트 요소**: 명암 4단계 규칙 — 배경 `#9BBC0F` / 보조 면 `#8BAC0F` / 강조 면 `#306230` / 텍스트·최강조 `#0F380F`. 중간톤이 필요하면 디더링으로만.
  - 콘텐츠 박스는 2px `#0F380F` 보더 + `#8BAC0F` 배경, 반경 0.
  - 차트·그래프는 색 대신 **디더링 패턴 4종**(솔리드 / 50% 체커 / 25% 도트 / 세로줄)으로 계열 구분 — 4색 제약의 정공법.
  - 리스트 불릿은 4×4 픽셀 정사각형.
  - 이미지는 4색 디더링 변환 필수.
  - 도트 매트릭스 격자 전 페이지 유지.

## ◾ Variation 3: 80s Vaporwave (베이퍼웨이브 · 원근 그리드)

* **핵심 컬러 (HEX)**: 배경 그라데이션 `#2B0F54 → #7A1E7A → #FF71CE` · 포인트 `#FF71CE`(핫핑크), `#01CDFE`(시안), `#05FFA1`(민트), `#B967FF`(퍼플) · 딥 `#120324` · 텍스트 `#FFFFFF`
* **팔레트 제한**: 네온 4색 + 그라데이션 배경.
* **사용 도형 & 그래픽**: **원근 와이어프레임 그리드**(지평선으로 수렴하는 3D 격자), 크롬/치프 텍스트, 야자수·조각상 실루엣, VHS 트래킹 노이즈 + 색수차. 픽셀은 V1·V2보다 크게(8px 단위) 쓰되 그라데이션과 혼용 — **레트로퓨처** 하이브리드. 격자 자체는 픽셀 계단 아닌 매끈한 선(80년대 CG 감각).
* **표지(Cover) 디자인**
  - 배경 상단 60%: 수직 그라데이션(`#2B0F54` → `#7A1E7A` → `#FF71CE` 지평선 쪽으로 밝아짐).
  - 배경 하단 40%: `#120324` + **원근 와이어프레임 그리드**(`#FF71CE` 1.5px 선, 세로선은 화면 중앙 소실점으로 수렴, 가로선은 아래로 갈수록 간격 넓어짐) + 그리드에 글로우 blur 8px.
  - 지평선(상하 경계, 화면 60% 지점)에 **거대 원**(지름 화면폭 44%) 배치 — 절반이 지평선 아래로 잠김. 원 채움은 `#FF71CE → #FFD23F` 수직 그라데이션 + 원 위로 가로 슬릿 5줄(배경색으로 뚫음) = 레트로 선(sun).
  - 제목은 지평선 위, 태양 원 **앞을 가로질러** 중앙 정렬. 대문자, 자간 +16%, 52pt. 텍스트는 크롬 효과 — `#01CDFE → #FFFFFF → #B967FF` 수직 그라데이션 채움 + 2px `#120324` 아웃라인 + 4px `#FF71CE` 하드 섀도(우하).
  - 제목 아래 일본어/한글 부제 관습: 픽셀 폰트 16pt `#01CDFE`, 자간 +30%.
  - 좌우 하단에 야자수 실루엣 2개(`#120324` 단색), 그리드 위에 세움.
  - 화면 전면에 VHS 트래킹 노이즈(가로 스트라이프 랜덤, 불투명 6%) + 색수차(적/청 ±2px).
  - 우측 상단에 `#05FFA1` 픽셀 텍스트로 날짜(`▶ REC` 스타일).
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 64px, 배경 `rgba(18,3,36,0.7)`. 좌측 섹션명 `#01CDFE` 픽셀 폰트 13pt 자간 +20%, 우측 `#FF71CE` 페이지 숫자. 하단 2px `#FF71CE` 선 + 글로우.
  - **본문 여백**: 좌우 72px, 상 44px / 하 **88px**(하단 그리드 영역 확보).
  - **포인트 요소**: 모든 내지 하단 22%에 원근 그리드 유지(불투명 60%) — 표지 규칙 승계.
  - 본문 배경은 `#2B0F54` 단색으로 정리(그라데이션은 표지·간지에만) — 가독 확보.
  - 콘텐츠 박스는 `rgba(255,113,206,0.08)` 면 + 1.5px `#01CDFE` 보더 + 반경 0 + 시안 글로우.
  - 강조 수치는 크롬 그라데이션 텍스트 48pt + 핑크 하드 섀도.
  - 리스트 불릿은 8px `#05FFA1` 정사각형 또는 `▶` 삼각형.
  - 이미지는 색수차 + 스캔라인 + 채도 과포화 처리.
  - 금지: 픽셀 폰트로 본문 장문 작성(제목·라벨까지만). 본문은 일반 산세리프 15pt.
