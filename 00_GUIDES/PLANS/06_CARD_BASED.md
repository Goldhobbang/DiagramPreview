# 06. 카드 기반 디자인 (Card-based Design)
> 정보를 독립된 카드 단위로 모듈화. 카드의 **간격·그림자 층위·모서리 반경**이 스타일을 결정한다. 뉴모피즘과 달리 카드는 배경과 **다른 색**을 갖는다.

**공통 원칙**: 카드 하나 = 정보 하나. 카드 내부 패딩은 최소 24px. 그리드 거터는 카드 반경의 1.5배 이상.

---

## ◾ Variation 1: Clean Stack (SaaS 대시보드형)

* **핵심 컬러 (HEX)**: 배경 `#F5F7FA` · 카드 `#FFFFFF` · 포인트 `#3B82F6`, 보조 `#10B981`(긍정) / `#F43F5E`(부정) · 텍스트 `#0F172A` / 보조 `#64748B` · 보더 `#E5E9F0`
* **사용 도형 & 그래픽**: 반경 16px 카드, 1px `#E5E9F0` 보더 + 아주 얕은 그림자(`0 1px 3px rgba(15,23,42,0.06)`). 원형 아이콘 칩, 얇은 라인 차트, 태그 알약(높이 24px). 그라데이션 최소.
* **표지(Cover) 디자인**
  - 배경 `#F5F7FA`. **12컬럼 그리드가 실제로 드러나는 대시보드 구조**.
  - 화면 좌측 7컬럼에 큰 흰 카드(세로 62%, 반경 24px) — 그 안에 제목 좌측 정렬 44pt Bold `#0F172A`, 상단에 `#3B82F6` 알약 태그.
  - 우측 5컬럼에는 작은 카드 3개를 세로로 스택(각 높이 균등, 간격 20px): 각각 아이콘 칩 + 숫자 + 라벨(핵심 지표 프리뷰).
  - 우측 카드 중 하나만 배경을 `#3B82F6`로 반전, 흰 텍스트 — 시선 앵커.
  - 배경에 `#E5E9F0` 1px 그리드 라인을 4% 불투명으로 은은히 노출(그리드 정체성 강조).
  - 하단 좌측 카드 밖에 발표자·날짜 12pt `#64748B`.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 76px 흰 카드형 바(반경 0, 하단 1px `#E5E9F0`). 좌측 섹션명 + 우측에 `#3B82F6` 알약 태그로 페이지 표기.
  - **본문 여백**: 좌우 64px, 상 32px / 하 48px. 12컬럼 · 거터 24px 고정.
  - **포인트 요소**: 카드 크기는 1×1 / 2×1 / 2×2 세 종류로 제한 — 자유 크기 금지.
  - 카드 상단 4px 컬러 스트립으로 카테고리 구분(`#3B82F6` / `#10B981` / `#F43F5E`).
  - 증감 수치는 `#10B981` ▲ / `#F43F5E` ▼ 아이콘 + 색상.
  - 호버/강조 상태는 그림자 한 단계 상승(`0 8px 24px rgba(15,23,42,0.10)`)으로만 표현.

## ◾ Variation 2: Tinted Deck (틴티드 카드 · 지그재그)

* **핵심 컬러 (HEX)**: 배경 `#F0FBF8` · 카드 틴트 `#14B8A6` 계열 3단계(`#CCFBF1` / `#99F6E4` / `#5EEAD4`) · 딥 `#0F766E` · 텍스트 `#134E4A` / 보조 `#5A8C86`
* **사용 도형 & 그래픽**: **보더도 그림자도 없이 색 틴트만으로 카드 분리**(V1의 흰카드+보더와 정반대). 반경 28px 큰 라운드. 카드 안쪽에 대형 반투명 아이콘 워터마크(불투명 12%). 카드끼리 살짝 겹침 허용.
* **표지(Cover) 디자인**
  - 배경 `#F0FBF8`. **지그재그 계단 구조** — 카드 3장을 좌→우로 내려가며 어긋나게 배치.
    - 카드 A(`#CCFBF1`, 가로 46% × 세로 30%): 좌측 상단, 0° 정렬
    - 카드 B(`#99F6E4`, 가로 52% × 세로 32%): 중앙, A보다 우측 18% · 아래 22% 이동, 카드 A와 모서리 5% 겹침
    - 카드 C(`#5EEAD4`, 가로 40% × 세로 26%): 우측 하단, B와 겹침
  - 제목은 **카드 B 안에** 좌측 정렬, 40pt Bold `#0F766E`. 카드 경계를 넘어가지 않게 제한.
  - 카드 A에는 카테고리 라벨만, 카드 C에는 날짜·발표자만 — 정보를 3장에 분산.
  - 각 카드 우측 하단에 지름 140px 아이콘 워터마크(카드 색보다 한 단계 진한 톤, 불투명 20%)가 카드 경계에 잘림.
* **전역(Global) 디자인**
  - **상단 헤더**: 헤더 바 없음. 좌측 상단 `#CCFBF1` 라운드 태그(반경 20px, 높이 36px) 안 섹션명 `#0F766E`.
  - **본문 여백**: 좌우 76px, 상 56px. 카드 배치는 정렬 그리드를 쓰되 **행마다 좌우 오프셋 24px 교대**로 지그재그 리듬 유지.
  - **포인트 요소**: 카드 틴트 3단계로 정보 위계 표현 — 연할수록 보조, 진할수록 핵심.
  - 텍스트는 항상 `#134E4A` 단일(틴트 위 가독 확보). 흰 텍스트는 `#5EEAD4` 카드에서도 금지.
  - 카드 겹침은 최대 2장까지, 겹치는 면적 8% 이내.
  - 차트는 카드 안에 틴트 면 채움 영역형으로.

## ◾ Variation 3: Dark Card (다크 · 좌측 사이드 레일)

* **핵심 컬러 (HEX)**: 배경 `#000000` · 카드 `#1C1C1E` / 상위 카드 `#2C2C2E` · 포인트 `#FF375F`(레드핑크), 보조 `#FFD60A` · 텍스트 `#F2F2F7` / 보조 `#8E8E93`
* **사용 도형 & 그래픽**: 반경 20px 카드, 보더 없음, **그림자 대신 명도 계층**(검정 배경 위 카드가 밝아짐). 카드 상단에 1px `#3A3A3C` 이너 하이라이트. 포인트 컬러는 면적 아주 작게, 대신 채도 최대.
* **표지(Cover) 디자인**
  - 배경 순수 `#000000`. **좌측 세로 레일 + 우측 대형 카드 구조**(V1 그리드·V2 지그재그와 분리).
  - 좌측 12% 폭을 세로 레일로 비워 두고, 그 안에 지름 10px 점 5개를 세로 등간격 배치(첫 점만 `#FF375F`, 나머지 `#3A3A3C`) — 챕터 인디케이터.
  - 우측 88% 영역에 대형 카드(`#1C1C1E`, 반경 28px, 화면 상하 여백 각 8%)를 풀블리드에 가깝게 배치.
  - 제목은 그 카드 안 **좌측 하단**에 배치, 56pt Bold `#F2F2F7`. 제목 위에 `#FF375F` 알약 태그(높이 28px).
  - 카드 우측 상단 안쪽에 `#2C2C2E` 소형 카드(가로 30% × 세로 26%, 반경 16px)를 겹쳐 올려 2단 계층 형성 — 그 안에 핵심 지표 하나.
  - 카드 우측 하단에 `#FFD60A` 지름 16px 원 1개.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 세로 레일을 **모든 내지에 유지**, 현재 챕터 점만 `#FF375F`로 점등 — 표지 규칙 승계 + 진행 표시 겸용.
  - **본문 여백**: 레일 우측 40px부터 콘텐츠 시작, 우 64px, 상 48px / 하 56px.
  - **포인트 요소**: 카드 2단 계층 규칙 유지 — `#1C1C1E`(기본) 위에 `#2C2C2E`(강조) 만 허용, 3단 금지.
  - 구분선은 `#3A3A3C` 1px, 카드 내부에서만 사용.
  - 강조 수치는 `#FF375F` 48pt Bold, 슬라이드당 1개.
  - 이미지 카드는 반경 20px 마스크 + 하단 40% 검정 그라데이션 오버레이 후 흰 텍스트.
