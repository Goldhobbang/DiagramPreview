# 18. 네온 / 사이버펑크 (Neon / Cyberpunk)
> 어둠 위 발광. 17번 베이퍼웨이브(V3)와 구분: 거기는 **노스탤지어·파스텔 네온**, 여기는 **디스토피아·고채도 네온 + 정보 과밀**.

**공통 원칙**: 배경은 순검정 금지 — 색이 섞인 딥 톤(`#0B0014` 등). 네온은 **면적 15% 이내**, 대신 채도 최대 + 글로우 2겹(안쪽 blur 4px 100% / 바깥 blur 24px 40%). 글로우 없는 네온색은 그냥 촌스러운 색.

---

## ◾ Variation 1: Blade Magenta (블레이드 · 수직 도시 스카이라인)

* **핵심 컬러 (HEX)**: 배경 `#0B0014` · 네온 `#FF00A0`(마젠타), 보조 `#00E5FF`(시안) · 딥 면 `#160423` · 안개 `#3A0B4A` · 텍스트 `#F2E6F5` / 보조 `#9A7BA8`
* **사용 도형 & 그래픽**: **수직 네온 스트립**(간판 기둥), 도시 실루엣, 비 내리는 사선 라인(1px, 불투명 12%, 75°), 습기 안개 그라데이션, 한자·가타카나 장식 활자. 네온 튜브 표현 — 흰색 코어 1px + 컬러 글로우 2겹.
* **표지(Cover) 디자인**
  - 배경 `#0B0014` + 하단 40%에 `#3A0B4A` 안개 그라데이션(위로 페이드).
  - **수직 스트립 구조** — 화면을 세로로 관통하는 네온 기둥들이 도시 간판처럼 늘어섬.
    - 좌측 8% 지점: 폭 6px 마젠타 네온 세로 스트립(상하 전폭), 글로우 2겹
    - 우측 18% 지점: 폭 3px 시안 네온 세로 스트립, 화면 상단 60%까지만
    - 우측 6% 지점: 폭 10px 마젠타 스트립, 하단 55%만
  - 각 스트립 옆에 90° 회전 세로 텍스트(가타카나·한자 장식 + 카테고리명) 10pt `#9A7BA8`, 자간 +30%.
  - 화면 하단 30%에 도시 실루엣(`#160423` 단색, 불규칙 높이 빌딩 라인) + 빌딩 창문에 1~2px 네온 점 산발.
  - 제목은 화면 중앙 좌측 정렬(좌 여백 100px), 상단에서 42% 지점, 48pt Bold `#F2E6F5`.
    - 제목 아래 한 줄만 `#FF00A0` 네온 텍스트(코어 흰색 + 마젠타 글로우) — 간판 느낌.
  - 제목 좌측에 마젠타 세로 바 4px(높이 = 제목 블록 높이) 밀착.
  - 화면 전면에 75° 비 사선 라인(1px `#9A7BA8`, 불투명 10%, 간격 40px 랜덤).
  - 우측 하단에 시안 대괄호 프레임 `[ ]` 안 날짜 Courier 11pt.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 68px, 하단에 마젠타 2px 네온 선 + 글로우. 좌측 섹션명 `#F2E6F5` 13pt, 그 앞에 시안 `//` 기호. 우측 `03/24` Courier `#00E5FF`.
  - **본문 여백**: 좌우 76px, 상 40px / 하 56px. **좌측 8% 마젠타 세로 스트립을 전 페이지 유지** — 표지 규칙 승계.
  - **포인트 요소**: 콘텐츠 박스는 `#160423` 면 + 1px `rgba(255,0,160,0.35)` 보더 + 반경 0(각진 사이버). 좌상단·우하단 모서리만 4px 잘라냄(chamfer).
  - 강조 박스 1개만 보더를 시안 네온으로 + 글로우.
  - 리스트 불릿은 `▸` 또는 3px 마젠타 정사각형.
  - 강조 수치는 `#00E5FF` 56pt + 글로우 2겹.
  - 비 사선·안개는 내지에서 불투명 절반으로.
  - 텍스트 순백 금지(`#F2E6F5`).

## ◾ Variation 2: Toxic Circuit (독성 그린 · 회로 기판)

* **핵심 컬러 (HEX)**: 배경 `#050A0E` · 네온 `#39FF14`(톡식 그린), 보조 `#FF6B00`(경고 오렌지) · 딥 면 `#0B1419` · 회로선 `#1A3D28` · 텍스트 `#D6FFD0` / 보조 `#5A8A5A`
* **사용 도형 & 그래픽**: **PCB 회로 트레이스** — 직각과 45°로만 꺾이는 선(곡선 절대 금지), 회로 노드 원(비아), 육각 패드. 데이터 스트림 텍스트, 터미널 로그, HUD 조준 브래킷. V1 수직스트립 → 여기는 **직각 회로망(수평·수직·45° 격자)**.
* **표지(Cover) 디자인**
  - 배경 `#050A0E`.
  - **회로 기판 구조** — 화면 전체에 PCB 트레이스 네트워크를 깔되, 중앙은 비워 제목 공간 확보.
    - 트레이스: 1.5px `#1A3D28` 선이 직각/45°로 꺾이며 화면 가장자리에서 중앙 방향으로 뻗음. 20~30개 경로.
    - 그중 **3~4개 경로만 `#39FF14` 활성**(글로우 2겹) — 나머지는 비활성 딥그린.
    - 경로 꺾임점·끝점에 지름 8px 원형 비아(활성 경로만 그린 발광).
  - 화면 중앙에 육각형 프레임(한 변 화면폭 22%, 1.5px `#39FF14`, 글로우) — 활성 트레이스 4개가 이 육각형에 접속.
  - 제목은 육각형 **안** 중앙 정렬, 40pt Bold `#D6FFD0`. 최대 2줄.
  - 육각형 위·아래에 HUD 브래킷 `⌐ ¬` 형태 마커.
  - 좌측 가장자리를 따라 세로로 흐르는 데이터 스트림 텍스트(Courier 9pt `#1A3D28`, 16진수 나열, 불투명 40%).
  - 우측 상단에 `#FF6B00` 경고 삼각 아이콘 + `SYS.STATUS: ACTIVE` Courier 10pt.
  - 하단에 진행 바 — 셀 20칸 분할, 6칸만 `#39FF14` 점등, 나머지 `#1A3D28`.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 60px `#0B1419` 바 + 하단 1px `#1A3D28` 선. 좌측 섹션명 Courier 12pt `#39FF14` 대문자 자간 +14%, 우측 `[03/24]`.
  - **본문 여백**: 좌우 72px, 상 36px / 하 60px.
  - **포인트 요소**: 콘텐츠 박스는 `#0B1419` 면 + 1px `#1A3D28` 보더 + **네 모서리에 HUD 브래킷**(ㄱ자, 그린, 각 16px). 반경 0.
  - 박스끼리 연결이 필요하면 회로 트레이스(직각/45°)로 연결 — 곡선·대각 자유선 금지.
  - 강조 박스는 보더를 `#39FF14`로 + 글로우.
  - 리스트 불릿은 `>` 또는 육각 4px.
  - 강조 수치는 `#39FF14` 52pt + 글로우, 경고·감소값만 `#FF6B00`.
  - 표는 Courier 모노스페이스 + 1px 그린 격자.
  - 배경 회로 트레이스 내지에서도 유지(불투명 45%, 비활성만).

## ◾ Variation 3: Cyber Amber (앰버 · 대각 슬래시 · 저채도 산업)

* **핵심 컬러 (HEX)**: 배경 `#12060B` · 네온 `#FFB300`(앰버), 보조 `#FF3D3D`(레드) · 딥 면 `#1F0F14` · 러스트 `#5C3A1E` · 텍스트 `#F5E6D3` / 보조 `#A08770`
* **사용 도형 & 그래픽**: V1·V2보다 **채도 낮고 거친 산업 톤**. 대각 슬래시(경고 스트라이프 45°), 스텐실 서체, 녹·긁힘 텍스처(노이즈 10%), 리벳·해치 패널. 네온은 앰버 하나로 절제, 글로우도 약하게(blur 16px, 30%) — 발광보다 **불빛 반사**에 가깝게.
* **표지(Cover) 디자인**
  - 배경 `#12060B` + 거친 그레인 10% + 좌상단에서 들어오는 약한 앰버 조명 그라데이션(불투명 14%).
  - **대각 슬래시 분할 구조**(V1 수직 · V2 직각격자와 완전 분리) — 화면을 좌하→우상 방향 38° 대각선으로 가름.
    - 대각선 위쪽: `#12060B` 유지, 비교적 비움
    - 대각선 아래쪽: `#1F0F14` 패널 면 + 리벳 원 8개(모서리를 따라 등간격, 지름 10px, `#5C3A1E`)
  - 대각 경계선 자체를 **경고 스트라이프 띠**로 처리 — 폭 32px, 45° 앰버/딥 교대 스트라이프, 가장자리 긁힘.
  - 제목은 대각선 **위쪽 영역**에 좌측 정렬(좌 여백 88px), 스텐실 계열 Bold 46pt `#F5E6D3`. 글자 일부에 스텐실 특유의 끊김(브리지) 표현.
  - 제목 위에 `#FFB300` 4px 수평 바(길이 100px) + 그 위 `WARNING` 류 라벨 10pt 자간 +28%.
  - 대각선 아래 패널 안에 정보 블록 3개를 45° 축에 맞춰 계단식 배치 — 각각 앰버 아이콘 + 라벨 + 수치.
  - 우측 상단에 `#FF3D3D` 원형 경고등(지름 20px + 약한 글로우) 1개.
  - 하단 좌측에 Courier 10pt `#A08770` 메타 정보(버전·날짜) 나열.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 64px `#1F0F14` 패널 + 하단에 경고 스트라이프 띠(높이 8px, 45° 앰버/딥). 좌측 섹션명 스텐실 13pt `#FFB300`, 우측 `03/24` Courier.
  - **본문 여백**: 좌우 74px, 상 40px / 하 56px.
  - **포인트 요소**: 콘텐츠 박스는 `#1F0F14` 면 + 1px `#5C3A1E` 보더 + **모서리 2곳(좌상·우하) 12px 대각 절단**(chamfer) — 표지 대각 규칙 승계.
  - 각 박스 좌상단에 리벳 원 2개.
  - 강조 박스만 보더 `#FFB300` + 약한 글로우.
  - 리스트 불릿은 앰버 대각 슬래시 `/` 또는 4px 마름모.
  - 강조 수치는 스텐실 54pt `#FFB300`, 경고값만 `#FF3D3D`.
  - 섹션 구분은 경고 스트라이프 띠(높이 12px).
  - 그레인·긁힘 텍스처 전 페이지 유지 — 이 베리에이션의 정체성(V1 습기·V2 클린회로와 촉감 분리).
  - 앰버 외 네온색 추가 금지(레드는 경고 전용, 페이지당 1회).
