# 11. 네오 브루탈리즘 (Neo-Brutalism)
> 브루탈리즘의 날것 태도 + 형광 원색 + **하드 섀도**. 낡음이 아니라 **의도적 촌스러움과 유쾌함**.
> 09번 브루탈리즘과 구분: 여기는 **3~4px 검정 보더 + 오프셋 하드 섀도(blur 0) + 고채도 팝 컬러**. 밝고 시끄럽고 친절한 쪽.

**공통 스펙**: 보더 `3px solid #000000` 전 요소 공통. 그림자 `box-shadow: 6px 6px 0 #000000`(blur 0, 확산 0). 반경 0~8px. 그라데이션 금지. 호버/강조 = 그림자 오프셋 축소(눌림).

---

## ◾ Variation 1: Yellow Block (옐로 팝 · 계단 오프셋)

* **핵심 컬러 (HEX)**: 배경 `#FFE500` · 면 `#FFFFFF` · 보더·섀도 `#000000` · 포인트 `#FF5C00`(오렌지), 보조 `#0066FF`(블루), `#00D9A3`(민트) · 텍스트 `#000000`
* **사용 도형 & 그래픽**: 직각 사각형(반경 4px), 정원, 별 8각 스파클, 손그림 느낌 굵은 화살표. 도트 패턴(지름 8px, 간격 28px, 검정). 서체는 굵은 산세리프(Archivo Black / Space Grotesk Bold). 모든 요소에 검정 보더 + 하드 섀도.
* **표지(Cover) 디자인**
  - 배경 `#FFE500` 전면 + 검정 도트 패턴 불투명 8%.
  - **계단식 오프셋 스택 구조** — 크기 다른 블록 3개를 우하 방향으로 24px씩 어긋나게 겹쳐 쌓음.
    - 뒤 블록: `#0066FF`, 가로 64% × 세로 34%, 보더 3px, 섀도 없음
    - 중간 블록: `#00D9A3`, 같은 크기, 뒤 블록에서 좌상으로 24px 이동
    - 앞 블록: `#FFFFFF`, 같은 크기, 다시 24px 이동, 섀도 `8px 8px 0 #000`
  - 제목은 흰 앞 블록 안에 좌측 정렬, 46pt Black `#000000`, 행간 0.95.
  - 제목 첫 단어만 `#FF5C00` + 그 단어 뒤에 검정 하이라이트 블록.
  - 스택 우측 상단 바깥에 8각 스파클(`#FF5C00`, 한 변 72px, 검정 보더) 1개가 스택 모서리에 걸침.
  - 좌측 하단에 알약형 태그(`#FF5C00`, 보더 3px, 섀도 `5px 5px 0`) 안 카테고리 흰 텍스트.
  - 우측 하단에 손그림 굵은 화살표(검정, 획 8px)가 스택을 가리킴.
* **전역(Global) 디자인**
  - **상단 헤더**: 전폭 흰 바(높이 76px, 하단 보더 3px 검정). 좌측에 `#FF5C00` 사각 블록(48×48, 보더) + 섹션명. 우측에 `#0066FF` 원(지름 44px, 보더) 안 페이지 숫자.
  - **본문 여백**: 좌우 64px, 상 36px / 하 56px.
  - **포인트 요소**: 콘텐츠 카드 = 흰 면 + 보더 3px + 섀도 `6px 6px 0 #000`. 카드끼리 간격 28px(섀도 먹지 않게).
  - 카드 색은 흰색 기본, 페이지당 1장만 컬러 면(`#00D9A3` 또는 `#0066FF`).
  - 리스트 불릿은 검정 정사각형 12px.
  - 강조 수치는 60pt Black + 텍스트에 2px 검정 아웃라인 + `4px 4px 0` 오렌지 텍스트 섀도.
  - 배경 도트 패턴 내지에서도 유지(불투명 6%).

## ◾ Variation 2: Cyan Punch (시안 · 회전 태그 산포)

* **핵심 컬러 (HEX)**: 배경 `#00E5FF` · 면 `#FFF8E7`(크림) · 보더·섀도 `#000000` · 포인트 `#FF2E63`(핫핑크), 보조 `#8B5CF6`(퍼플), `#FFD600`(옐로) · 텍스트 `#000000`
* **사용 도형 & 그래픽**: **회전된 요소**가 핵심 — 태그·배지·스티커가 -12°~+12°로 기울어져 산포. 알약형, 말풍선(꼬리 있는), 리본 배너, 지그재그 하단 가장자리. 굵은 검정 아웃라인 손그림 아이콘. V1 정렬 스택 → 여기는 **비정렬 회전 산포**.
* **표지(Cover) 디자인**
  - 배경 `#00E5FF` + 검정 굵은 사선 스트라이프(폭 12px, 간격 60px, 45°, 불투명 10%).
  - **중앙 말풍선 + 주변 스티커 산포 구조**.
  - 화면 중앙에 대형 말풍선(가로 68% × 세로 42%, 크림 `#FFF8E7`, 반경 24px, 좌하단에 삼각 꼬리, 보더 4px, 섀도 `10px 10px 0 #000`), -2° 회전.
  - 제목은 말풍선 안 중앙 정렬, 42pt Black `#000000`. 핵심 단어에 `#FFD600` 형광 하이라이터 블록(검정 보더 2px).
  - 말풍선 주변에 스티커 4개를 서로 다른 각도로 산포:
    - 좌상단: `#FF2E63` 알약 태그(-10°) — 카테고리
    - 우상단: `#8B5CF6` 원형 배지(+8°, 지름 110px) — 안에 별 아이콘
    - 좌하단: `#FFD600` 리본 배너(+6°) — 날짜
    - 우하단: 크림 사각 태그(-7°) — 발표자
  - 모든 스티커에 보더 3px + 섀도 `5px 5px 0 #000`.
  - 화면 하단 가장자리에 지그재그 검정 띠(높이 28px, 삼각 톱니).
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 상단에 알약 태그(`#FF2E63`, -4° 회전, 보더 3px, 섀도) 안 섹션명 흰 텍스트. 우측 상단에 원형 배지(`#8B5CF6`, +4°) 안 페이지 숫자.
  - **본문 여백**: 좌우 68px, 상 60px / 하 68px. 배경은 내지에서 `#FFF8E7` 크림으로 전환(시안은 포인트 요소로만) — 표지 대비 반전.
  - **포인트 요소**: 콘텐츠 박스는 흰 면 + 보더 3px + 섀도 `6px 6px 0`, **회전 ±2° 이내로 제한**(표지보다 얌전하게, 가독).
  - 각 박스 좌상단 모서리에 작은 회전 태그(±8°)가 걸쳐 붙음 — 표지 스티커 규칙 승계.
  - 강조 문구는 말풍선 형태 박스에.
  - 리스트 불릿은 검정 아웃라인 별 14px.
  - 섹션 구분은 지그재그 띠(높이 16px).

## ◾ Variation 3: Lilac Slab (라일락 파스텔 · 좌우 2열 그리드)

* **핵심 컬러 (HEX)**: 배경 `#C4B5FD`(라일락) · 면 `#FFFFFF` · 보더·섀도 `#1E1B2E`(잉크 네이비 — 순검정 대신) · 포인트 `#F97316`(오렌지), 보조 `#22C55E`(그린), `#FDE047`(레몬) · 텍스트 `#1E1B2E`
* **사용 도형 & 그래픽**: V1·V2보다 **부드러운 파스텔 톤 + 큰 반경(16px)**. 보더 3px `#1E1B2E`, 섀도 `6px 6px 0 #1E1B2E`. 체크 패턴, 물결 하단선, 두꺼운 아웃라인 이모지풍 아이콘. 정렬은 **엄격한 2열 그리드**(V1 계단·V2 산포와 완전 분리).
* **표지(Cover) 디자인**
  - 배경 `#C4B5FD` + 흰색 체크 패턴(격자 선 2px, 간격 72px, 불투명 22%).
  - **좌우 2열 균등 분할 구조**, 가운데 거터 32px.
    - 좌열: 세로로 긴 흰 패널(가로 100%, 세로 78%, 반경 16px, 보더, 섀도) — 제목 자리. 제목 좌측 정렬 하단 기준, 44pt Bold `#1E1B2E`. 제목 위에 `#F97316` 알약 태그.
    - 우열: 정사각형에 가까운 블록 3개를 세로로 균등 스택(간격 24px, 각 반경 16px, 보더, 섀도) — 위에서부터 `#FDE047` / `#22C55E` / `#FFFFFF`. 각 블록 안에 두꺼운 아웃라인 아이콘 1개 + 짧은 라벨.
  - 좌열 패널 하단 가장자리를 **물결(wave) 형태**로 처리 — 유일한 곡선 유희.
  - 화면 하단 전폭에 `#1E1B2E` 물결 띠(높이 40px).
  - 발표자·날짜는 좌열 패널 하단 물결 위 작은 텍스트.
* **전역(Global) 디자인**
  - **상단 헤더**: 전폭 흰 바(높이 72px, 반경 16px, 좌우 여백 48px, 보더, 섀도 `5px 5px 0`) — 떠 있는 캡슐 헤더. 좌측 섹션명, 우측 `#F97316` 원 안 페이지 숫자.
  - **본문 여백**: 좌우 60px, 상 32px / 하 60px. **2열 그리드 유지**(1:1 또는 1:2), 거터 32px 고정.
  - **포인트 요소**: 카드 반경 16px 통일, 보더 3px, 섀도 `6px 6px 0 #1E1B2E`.
  - 카드 배경은 흰색 기본 + 페이지당 최대 2장까지 파스텔 컬러(`#FDE047` / `#22C55E`).
  - 리스트 불릿은 두꺼운 아웃라인 체크 아이콘 16px.
  - 강조 수치는 52pt Bold + 하단에 `#F97316` 굵은 밑줄 블록(높이 10px, 보더 없음).
  - 섹션 구분·하단 마감은 물결 띠로 통일.
  - 순검정 사용 금지 — 모든 검정 자리에 `#1E1B2E` 사용(파스텔 톤과의 조화).
