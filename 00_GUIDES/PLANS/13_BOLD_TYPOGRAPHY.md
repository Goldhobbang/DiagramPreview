# 13. 볼드 타이포그래피 (Bold Typography)
> 글자가 곧 그래픽. 이미지·도형이 아니라 **활자의 크기·무게·잘림·간격**이 화면을 지배한다.

**공통 원칙**: 서체는 2종 이내(제목용 초굵은 것 1 + 본문용 1). 제목 행간 0.82~0.92(글자끼리 거의 닿게). 자간은 크기 커질수록 좁게(-2%~-4%). 화면의 40% 이상을 활자가 점유. 도형은 활자를 보조할 때만.

---

## ◾ Variation 1: Black & Bone (스위스 · 화면 밖 잘림)

* **핵심 컬러 (HEX)**: 배경 `#F5F1E8`(본 화이트) · 포인트 `#111111` · 액센트 `#FF3B00`(버밀리언) · 텍스트 `#111111` / 보조 `#7A756B`
* **사용 도형 & 그래픽**: 도형 거의 없음. 1px 헤어라인, 굵은 4px 룰. 서체 — 제목 Helvetica Now Black / Archivo Black, 본문 Helvetica Regular. 그래픽 요소는 **활자 자체를 화면 밖으로 잘라내는 것**.
* **표지(Cover) 디자인**
  - 배경 `#F5F1E8` 전면.
  - **화면 밖 잘림(bleed crop) 구조** — 제목을 화면보다 크게 키워 좌우 양끝이 잘리게 배치.
  - 제목 3줄, 각 줄 크기 다르게(1줄 140pt / 2줄 96pt / 3줄 140pt), 행간 0.85, 좌측 정렬 좌 여백 48px. 1·3줄은 우측이 화면 밖으로 잘림.
  - 2줄만 `#FF3B00` — 색이 아니라 **줄 단위로** 강조.
  - 제목 블록 위에 4px `#111111` 수평 룰(전폭), 아래에도 1px 룰.
  - 상단 룰 위에 8pt 대문자 메타 정보를 좌우 양끝 정렬(좌: 카테고리 / 우: 날짜), 자간 +24%.
  - 하단 1px 룰 아래에 발표자·기관명 11pt.
  - 그 외 도형 전무. 활자와 3개의 선만.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 64px. 상단에 1px `#111111` 룰 + 그 아래 좌측 섹션명 10pt 대문자 자간 +20%, 우측 페이지 숫자.
  - **본문 여백**: 좌 48px / 우 48px, 상 40px / 하 56px. 12컬럼, 거터 20px.
  - **포인트 요소**: 카드·박스 없음. 정보 구분은 4px 굵은 룰(대분류) / 1px 얇은 룰(소분류) 두 단계로만.
  - 소제목은 32pt Black, 본문은 15pt Regular — **중간 크기 금지**(대비를 극단으로).
  - 인용문은 72pt Black + 좌측 정렬, 인용부호 없이 크기로만 표현.
  - `#FF3B00`는 페이지당 1개 요소(단어 하나 또는 룰 하나).
  - 이미지 사용 시 흑백 + 활자 아래 배치, 절대 활자를 가리지 않음.

## ◾ Variation 2: Editorial Red (매거진 세리프 · 활자 액자)

* **핵심 컬러 (HEX)**: 배경 `#FFFFFF` · 포인트 `#D7263D`(딥 레드) · 딥 `#1A1A1A` · 보조 면 `#F7E9EA`(연분홍) · 텍스트 `#1A1A1A` / 보조 `#8A7A7C`
* **사용 도형 & 그래픽**: 서체 — 제목 고대비 디독(Didot / Playfair Display) Bold, 본문 산세리프. 세리프의 **얇은 획과 굵은 획 대비**가 그래픽. 얇은 1px 세리프 룰, 드롭캡, 컬럼 구분선. V1 산세리프 잘림 → 여기는 **세리프 + 중앙 대칭 액자**.
* **표지(Cover) 디자인**
  - 배경 `#FFFFFF`.
  - **중앙 대칭 활자 액자 구조** — 제목이 스스로 액자를 만듦.
  - 화면 상단 여백 100px 지점에 얇은 1px `#1A1A1A` 수평선(폭 화면 60%, 중앙 정렬).
  - 그 아래 제목 세리프 96pt, **중앙 정렬**, 행간 0.9. 2~3줄. 자간 -3%.
  - 제목 가운데 한 단어만 **이탤릭 + `#D7263D`** — 활자 스타일 자체로 강조.
  - 제목 아래 다시 얇은 수평선(폭 화면 30%, 중앙) → 위·아래 선 길이가 다른 비대칭 액자.
  - 제목 위에 소제목 대문자 산세리프 10pt, 자간 +36%, `#8A7A7C`.
  - 화면 좌우 가장자리에 세로 1px 룰(상하 여백 60px) 2줄 — 매거진 판면 느낌.
  - 하단 중앙에 `#F7E9EA` 알약 배지 + 날짜 세리프 12pt.
  - 배경 여백 넓게 유지 — 활자가 크되 밀도는 낮음.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 중앙에 섹션명 세리프 이탤릭 13pt `#D7263D` + 좌우로 뻗는 1px 룰(양쪽 각 120px). 우측 상단 구석에 페이지 숫자 세리프.
  - **본문 여백**: 좌우 92px, 상 56px / 하 64px. **2컬럼 조판**(거터 40px + 가운데 1px 세로 구분선).
  - **포인트 요소**: 본문 첫 문단에 드롭캡(3줄 높이, 세리프, `#D7263D`).
  - 소제목은 세리프 26pt Bold + 위에 1px 룰.
  - 인용문은 세리프 이탤릭 40pt, 좌우 여백 크게 들여쓰기, 위아래 1px 룰로 감쌈.
  - `#F7E9EA` 면은 요약·박스 기사용, 반경 0.
  - 수치 강조는 세리프 72pt `#D7263D` + 아래 캡션 10pt 대문자.
  - 이미지는 컬럼 폭에 맞춰 배치 + 하단 세리프 이탤릭 캡션.

## ◾ Variation 3: Electric Lime (형광 · 세로 회전 타이포)

* **핵심 컬러 (HEX)**: 배경 `#1C1C1C`(차콜) · 포인트 `#CBFF00`(일렉트릭 라임) · 보조 `#FFFFFF` · 딥 `#0A0A0A` · 텍스트 `#FFFFFF` / 보조 `#8A8A8A`
* **사용 도형 & 그래픽**: 서체 — 초압축 산세리프(Compressed / Condensed Black, 폭 좁고 키 큰 활자). **90° 회전 세로 타이포**, 활자 아웃라인(채움 없이 스트로크 2px), 활자 겹침. V1 잘림 · V2 세리프대칭 → 여기는 **세로축 + 아웃라인/채움 혼용**.
* **표지(Cover) 디자인**
  - 배경 `#1C1C1C`.
  - **수직 회전 타이포 구조** — 좌측 22% 영역에 대문자 세로 타이포(90° 회전, 아래→위 방향) 배치. 압축 서체 72pt, 자간 +12%, `#CBFF00`. 카테고리/기관명 용도.
  - 우측 78% 영역에 제목 가로 배치, 압축 Black 128pt, 행간 0.82, 좌측 정렬, 2~3줄.
    - 1줄: `#FFFFFF` 채움
    - 2줄: **아웃라인만**(채움 없음, 2px `#CBFF00` 스트로크)
    - 3줄: `#CBFF00` 채움
    → 줄마다 채움 방식이 달라 리듬 생성.
  - 제목 뒤에 같은 단어를 400pt로 확대해 `#252525`(배경보다 살짝 밝은 톤)로 깔아 고스트 레이어 생성 — 활자로 만든 배경.
  - 우측 하단에 `#CBFF00` 사각 블록(가로 25% × 세로 8%) + 검정 텍스트로 날짜.
  - 좌측 세로 타이포 옆에 1px `#CBFF00` 세로선이 상하 전폭 관통.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 세로 타이포 축(폭 22%)을 **모든 내지에 유지** — 안에 섹션명 90° 회전 배치, `#CBFF00`. 우측 상단에 페이지 숫자 압축체 24pt.
  - **본문 여백**: 세로 축 우측 48px부터 콘텐츠, 우 64px, 상 48px / 하 56px.
  - **포인트 요소**: 소제목은 압축 Black 40pt 대문자, `#CBFF00`.
  - 본문은 압축체 금지 — 일반 산세리프 15pt `#FFFFFF`(가독 확보). 압축체는 제목·수치에만.
  - 강조 수치는 압축 Black 96pt, 아웃라인 스타일 1개 / 채움 스타일 1개를 나란히 대비 배치.
  - 리스트 불릿은 `#CBFF00` 사각형 8px.
  - 고스트 레이어(대형 흐린 활자)를 내지에서도 우측 하단에 배치, 불투명 하되 `#252525` 톤 고정.
  - 구분선은 `#CBFF00` 2px, 폭은 짧게(120px).
