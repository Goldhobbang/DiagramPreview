# 08. 맥시멀리즘 (Maximalism)
> "More is more." 여백을 채우고 패턴·색·타이포를 겹친다. 다만 **혼돈이 아니라 통제된 과잉** — 그리드는 살아 있고 색 팔레트는 고정된다.

**공통 원칙**: 팔레트 5색 고정(그 이상 금지). 요소가 많을수록 **정렬은 더 엄격하게**. 슬라이드마다 "쉼 구역"(빈 면) 하나는 반드시 남긴다 — 없으면 읽히지 않는다.

## ◾ Variation 1: Baroque Jewel (바로크 주얼 · 대칭 액자)

* **핵심 컬러 (HEX)**: 배경 `#7B1E3B`(딥 와인) · 금 `#C9A227`, 라이트 금 `#F0D98C` · 딥 `#2A0E1B` · 보조 `#1F5F5B`(에메랄드) · 텍스트 `#F7EFE2`
* **사용 도형 & 그래픽**: 다마스크·아라베스크 패턴, 금색 라인 아트 프레임, 월계관·리본 오너먼트, 벨벳 텍스처(노이즈 8%). **금속 그라데이션**(`#F0D98C → #C9A227 → #8A6B14` 135°)으로 금 재질 표현. 좌우 완전 대칭.
* **표지(Cover) 디자인**
  - 배경 `#7B1E3B` 벨벳 + 전면에 다마스크 패턴을 `#2A0E1B` 위에 불투명 14%로 타일링(패턴 단위 240px).
  - **좌우 축 완전 대칭 액자 구조**. 화면 안쪽 여백 56px 지점에 금색 이중 프레임(바깥 3px + 안쪽 1px, 간격 8px)을 두름.
  - 프레임 네 모서리에 아라베스크 코너 오너먼트(금속 그라데이션, 각 120px), 상·하 변 중앙에 마름모 오너먼트.
  - 제목은 화면 정중앙 중앙 정렬, 세리프 52pt `#F7EFE2`. 제목 위·아래에 금색 장식 구분선(중앙이 마름모로 부푼 형태, 폭 320px) 대칭 배치.
  - 제목 뒤에 지름 420px 원형 메달리온(에메랄드 `#1F5F5B` 채움 + 금 1px 아웃라인, 불투명 45%).
  - 하단 중앙에 리본 형태 금색 배너 + 그 안 발표자·날짜 12pt.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 84px, 상단에 금색 3px 수평 이중선 + 중앙 정렬 섹션명(대문자, 자간 +20%, `#C9A227`). 좌우 끝에 소형 오너먼트 대칭.
  - **본문 여백**: 좌우 96px, 상 40px / 하 72px. 배경 다마스크 패턴은 내지에서 불투명 7%로 절반 낮춤(가독).
  - **포인트 요소**: 콘텐츠 박스는 `#2A0E1B` 면 + 금 1px 아웃라인 + 모서리 4곳 소형 오너먼트. 반경 0(각진 액자).
  - 리스트 불릿은 금색 마름모 8px.
  - 수치 강조는 금속 그라데이션 채운 세리프 56pt.
  - 좌우 대칭 규칙은 내지에서도 유지 — 2단 구성 시 반드시 균등 분할, 비대칭 금지.
  - 쉼 구역: 하단 20%는 오너먼트 없이 비움.

## ◾ Variation 2: Tropical Riot (트로피컬 · 대각 콜라주)

* **핵심 컬러 (HEX)**: 배경 `#00A878`(딥 그린) · 포인트 `#FF3D7F`(핫핑크), `#FFD23F`(옐로), `#00C2D1`(터콰이즈) · 딥 `#083D30` · 텍스트 `#FFFFFF` / 딥 텍스트 `#083D30`
* **사용 도형 & 그래픽**: **잎사귀 실루엣**(몬스테라·야자), 물결 리본, 지그재그 스트라이프, 원형 도트 패턴. 컷아웃 콜라주 방식(도형끼리 겹치며 서로 자름). 그라데이션 대신 **평면 원색 면**. V1 대칭 → 여기는 **대각선 45° 비대칭**.
* **표지(Cover) 디자인**
  - 배경 `#00A878` 위에 좌하단→우상단 **45° 대각 밴드** 3개(각 폭 다름: 120 / 64 / 200px)를 `#FFD23F` / `#00C2D1` / `#FF3D7F`로 흘려 배치.
  - 좌측 상단·우측 하단 모서리에서 대형 몬스테라 잎 실루엣(`#083D30`, 불투명 100%)이 화면 안으로 침입 — 각 잎 크기 화면 대각의 45%.
  - 제목은 화면 **중앙에서 좌하로 치우쳐** 배치, 좌측 정렬, 54pt ExtraBold `#FFFFFF`. 제목 각 줄마다 뒤에 `#083D30` 하이라이터 블록을 깔아 잎·밴드 위에서도 읽히게 함.
  - 제목 우측 상단에 `#FFD23F` 원(지름 200px) + 그 위에 `#FF3D7F` 지그재그 스트라이프 마스킹.
  - 화면 전면에 `#083D30` 도트 패턴(지름 6px, 간격 32px)을 불투명 12%로 오버레이.
  - 쉼 구역: 우측 하단 잎 안쪽 면.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 상단 `#FFD23F` 각진 태그(평행사변형, 15° 기울임) 안 섹션명 `#083D30`. 우측 상단에 45° 짧은 대각 밴드 3줄로 페이지 진행 표시.
  - **본문 여백**: 좌우 72px, 상 56px / 하 64px. 배경은 내지에서 `#F2FBF7`(라이트)로 전환 — 표지 딥그린과 반전.
  - **포인트 요소**: 콘텐츠 카드는 흰색 면 + **모서리 하나만 45° 잘린** 형태(각 카드마다 잘린 모서리 위치를 돌려가며 배치).
  - 각 카드 뒤에 원색 면(핑크/옐로/터콰이즈)을 8px 오프셋으로 깔아 **컬러 그림자** 효과.
  - 잎 실루엣은 내지에서 우측 하단 1개만, 불투명 15%.
  - 리스트 불릿은 작은 잎 아이콘 14px.

## ◾ Variation 3: Collage Pop (레트로 콜라주 · 격자 파괴)

* **핵심 컬러 (HEX)**: 배경 `#FFD400`(옐로) · 포인트 `#1A1A1A`(블랙), `#E4002B`(레드), `#0057FF`(블루), `#F5F0E6`(오프화이트) · 텍스트 `#1A1A1A`
* **사용 도형 & 그래픽**: **종이 찢김(torn paper) 가장자리**, 하프톤 도트, 테이프 조각, 스탬프·잉크 번짐, 잘라 붙인 활자(랜섬 노트). 텍스처: 신문지 그레인 10% + 인쇄 오프셋 어긋남(색 1~2px 밀림). V1 대칭·V2 대각 → 여기는 **불규칙 격자 + 회전**.
* **표지(Cover) 디자인**
  - 배경 `#FFD400` 전면 + 신문지 그레인.
  - **불규칙 격자 구조**: 화면을 크기가 제각각인 사각 조각 6~7개로 분할(마치 콜라주 붙임). 각 조각은 -6°~+8° 랜덤 회전, 가장자리는 찢긴 형태.
    - 가장 큰 조각(`#F5F0E6`, 화면 40%): 중앙 좌측, +3° 회전 — 제목 자리
    - 조각 2(`#E4002B`, 화면 18%): 우측 상단, -5° 회전
    - 조각 3(`#0057FF`, 화면 14%): 하단 중앙, +7° 회전
    - 나머지 소형 조각: 블랙 하프톤 패턴 면, 흑백 사진 컷
  - 제목은 큰 오프화이트 조각 위에 **글자마다 크기·서체·회전을 다르게** 한 랜섬 노트 방식(단, 베이스라인은 하나로 유지해 읽히게).
  - 조각 위에 반투명 테이프 그래픽 3개(흰색 40%, 폭 90px)를 모서리에 대각으로 붙임.
  - 우측 하단에 `#1A1A1A` 원형 스탬프(지름 120px, 아웃라인 3px, 안에 원형 배열 텍스트).
  - 쉼 구역: 좌측 하단 옐로 여백 그대로.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 상단에 찢긴 가장자리 `#F5F0E6` 조각(-2° 회전) 안 섹션명 `#1A1A1A` + 우측 상단 테이프 조각 위 페이지 숫자.
  - **본문 여백**: 좌우 68px, 상 60px. 배경은 내지에서 `#F5F0E6` 오프화이트로 전환, 옐로는 포인트 조각으로만.
  - **포인트 요소**: 콘텐츠 블록은 찢긴 가장자리 종이 조각 위에 올림, 회전은 **±3° 이내로 제한**(표지보다 얌전하게 — 가독).
  - 각 블록 상단에 테이프 1개 고정.
  - 강조 문구는 `#E4002B` 하이라이터 마커 스트로크(손그림 느낌, 끝이 거침).
  - 이미지는 흑백 변환 + 하프톤 도트 처리 후 `#0057FF` 또는 `#E4002B` 단색 오버레이(듀오톤).
  - 인쇄 오프셋 어긋남 효과는 제목과 강조 요소에만 적용.
