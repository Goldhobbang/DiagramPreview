# 19. 모노크롬 (Monochrome)
> 색상(hue) 하나만 쓰고 **명도·채도 계조만으로** 모든 위계를 만든다. 미니멀리즘(02번)과 구분: 미니멀은 요소 수를 줄이는 것, 모노크롬은 **요소는 많아도 색이 하나**.

**공통 원칙**: 색상값 하나 고정, 계조 5~7단계로 스케일 정의. 대비는 색이 아니라 **명도차 40 이상**으로 확보. 강조는 채도가 아니라 **가장 밝은 톤 ↔ 가장 어두운 톤의 반전**으로. 두 번째 색상 도입 금지.

---

## ◾ Variation 1: True Gray (무채색 · 계조 사다리)

* **계조 스케일 (HEX)**: `#000000` / `#2B2B2B` / `#575757` / `#8C8C8C` / `#C4C4C4` / `#E8E8E8` / `#FFFFFF` — 7단계
* **핵심 컬러**: 배경 `#FFFFFF` · 포인트 `#000000` · 텍스트 `#000000` / 보조 `#575757` · 면 `#E8E8E8`
* **사용 도형 & 그래픽**: 직각 사각형, 계조 사다리 블록, 하프톤 도트(명도를 도트 밀도로 표현), 1px~6px 룰 4단계. 그라데이션은 계조 사이 전환에만. 이미지는 전부 흑백 변환.
* **표지(Cover) 디자인**
  - 배경 `#FFFFFF`.
  - **계조 사다리 구조** — 화면 하단 38%를 세로 스트라이프 7개로 분할(각 폭 균등), 좌→우로 `#FFFFFF`부터 `#000000`까지 순차 채움. 스케일 자체를 표지 그래픽으로 노출.
  - 제목은 상단 62% 흰 영역에 좌측 정렬(좌 여백 84px), 상단에서 34% 지점, 58pt Bold `#000000`, 행간 0.95.
  - 제목 위에 6px `#000000` 수평 룰(길이 96px).
  - 제목 아래 부제 17pt `#575757`.
  - 계조 사다리 위 경계선을 따라 각 스트라이프 상단에 명도값 라벨(`0` `15` `34` ... ) 8pt Courier — 어두운 스트라이프에서는 흰색, 밝은 쪽은 검정으로 자동 반전.
  - 우측 하단 검정 스트라이프 위에 흰 텍스트로 날짜 11pt.
  - 좌측 흰 스트라이프 위에 검정 텍스트로 발표자 11pt.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 76px 흰 배경. 좌측 섹션명 13pt `#000000`, 우측 페이지 숫자. 하단 2px `#000000` 룰.
  - **본문 여백**: 좌우 80px, 상 40px / 하 64px. 12컬럼, 거터 24px.
  - **포인트 요소**: 정보 위계를 **면의 명도로만** 표현 — 최상위 `#000000` 면(흰 텍스트) / 2단계 `#575757` / 3단계 `#E8E8E8` / 기본 흰 면 + 1px `#C4C4C4` 보더.
  - 페이지당 검정 반전 블록 **1개만** — 시선 앵커.
  - 차트는 계열 구분을 명도 4단계 + 하프톤 패턴 2종으로(색 없이 8계열까지 구분 가능).
  - 리스트 불릿은 검정 정사각형 10px.
  - 강조 수치는 72pt Bold `#000000`, 단위는 `#8C8C8C`.
  - 이미지는 흑백 + 대비 강화, 캡션 10pt `#575757`.
  - 하단 우측에 축소 계조 사다리(폭 120px, 높이 8px, 7칸) 상시 배치 — 표지 규칙 승계.

## ◾ Variation 2: Blue Mono (딥 네이비 단색 · 명도 레이어)

* **계조 스케일 (HEX)**: `#050C1A` / `#0B2545` / `#13406E` / `#2C6BA8` / `#6E9FCE` / `#B9D3EA` / `#EAF2F9` — 색상 210° 고정, 명도만 변화
* **핵심 컬러**: 배경 `#0B2545` · 면 `#13406E` / `#050C1A` · 포인트 `#B9D3EA` · 텍스트 `#EAF2F9` / 보조 `#6E9FCE`
* **사용 도형 & 그래픽**: 반경 8px 사각형, 겹치는 반투명 레이어(같은 색 불투명도 차이로 계조 생성), 얇은 라인. **다크 베이스**라 V1(라이트)과 명암 방향이 반대. 그라데이션은 같은 색상 내 명도 전환만.
* **표지(Cover) 디자인**
  - 배경 `#0B2545`.
  - **겹침 레이어 구조**(V1 스트라이프 사다리와 분리) — 같은 색을 불투명도 다르게 겹쳐 깊이 생성.
    - 좌하단에서 우상단으로 뻗는 대형 사각 패널 3장을 15°씩 회전 없이 **평행 이동으로 어긋나게** 겹침:
      - 패널1(가장 뒤, 가장 큼): `#13406E`, 가로 72% × 세로 54%
      - 패널2: `#2C6BA8` 불투명 40%, 패널1에서 우상으로 56px 이동
      - 패널3(가장 앞, 가장 작음): `#050C1A`, 다시 56px 이동, 가로 54% × 세로 40%
    - 겹치는 구간에서 자연스럽게 중간 명도 생성 — 이것이 콘셉트.
  - 제목은 가장 앞 어두운 패널3 안에 좌측 정렬, 44pt Semi Bold `#EAF2F9`.
  - 제목 위에 `#B9D3EA` 2px 수평선(길이 72px).
  - 패널 바깥 우측 상단에 지름 160px 원(`#2C6BA8` 불투명 25%) 1개.
  - 좌측 하단 배경 위에 발표자·날짜 11pt `#6E9FCE`.
  - 화면 전면에 아주 얕은 비네트(`#050C1A` 불투명 20%, 가장자리).
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 72px `#050C1A` 바. 좌측 섹션명 13pt `#B9D3EA`, 우측 페이지 숫자 `#6E9FCE`. 하단 1px `#13406E`.
  - **본문 여백**: 좌우 78px, 상 40px / 하 60px.
  - **포인트 요소**: 콘텐츠 카드는 `#13406E` 면 + 반경 8px, 보더 없음(명도차로 분리). 강조 카드만 `#050C1A`(더 어둡게 = 더 앞으로) 또는 `#B9D3EA`(밝은 반전, 어두운 텍스트).
  - 카드 겹침 규칙 유지 — 페이지당 1쌍만 24px 오프셋으로 겹치게 배치.
  - 차트는 명도 5단계로 계열 구분, 격자선 `#13406E`.
  - 리스트 불릿은 `#6E9FCE` 원 8px.
  - 강조 수치는 `#B9D3EA` 56pt.
  - 텍스트 순백 금지(`#EAF2F9` 고정). 최저 대비 쌍은 `#EAF2F9` on `#13406E`까지만 허용.

## ◾ Variation 3: Sepia Mono (세피아 · 아카이브 · 대각 그리드)

* **계조 스케일 (HEX)**: `#1C130B` / `#4A3728` / `#6F5843` / `#96806A` / `#C0AE97` / `#E0D5C3` / `#F5EFE3` — 색상 30° 고정
* **핵심 컬러**: 배경 `#F5EFE3` · 포인트 `#4A3728` · 딥 `#1C130B` · 면 `#E0D5C3` · 텍스트 `#1C130B` / 보조 `#6F5843`
* **사용 도형 & 그래픽**: 세리프 타이포 중심, 아카이브 문서 감각. 얇은 1px 룰, 얕은 종이 텍스처(그레인 6%), 빈티지 사진 프레임, 스탬프 원형 마크. **대각 45° 얇은 해칭 패턴**으로 중간 명도 생성(V1 하프톤·V2 겹침과 계조 생성 방식 분리).
* **표지(Cover) 디자인**
  - 배경 `#F5EFE3` + 종이 그레인 + 가장자리 얕은 세피아 얼룩(불투명 10%).
  - **아카이브 카드 구조** — 오래된 도서관 색인 카드 감각.
  - 화면 안쪽 여백 56px 지점에 1px `#96806A` 사각 프레임 한 바퀴. 프레임 상단 변 중앙에 원형 스탬프 마크(지름 96px, 1.5px `#4A3728` 이중 원 + 원형 배열 텍스트) 하나가 선 위에 걸침.
  - 프레임 안쪽 상단 1/3 영역: 45° 대각 해칭 패턴(`#C0AE97` 0.5px, 간격 6px)으로 채워 중간 명도 면 생성. 그 위에 카테고리 라벨 대문자 세리프 11pt `#4A3728`, 자간 +26%.
  - 제목은 해칭 면 **아래**, 프레임 안 좌측 정렬(좌 여백 84px), 세리프 46pt `#1C130B`, 행간 1.1.
  - 제목 아래 1px `#96806A` 룰(전폭) + 그 아래 부제 세리프 이탤릭 16pt `#6F5843`.
  - 프레임 안쪽 하단에 색인 카드식 메타 나열 — 좌측 라벨(`DATE` `AUTHOR` `REF`) 9pt 대문자 `#96806A`, 우측 값 11pt `#4A3728`, 각 줄 사이 0.5px 점선.
  - 우측 하단 프레임 밖에 `#4A3728` 정사각형 24px 1개.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단에 1px `#96806A` 룰 + 그 아래 좌측 섹션명 세리프 12pt `#4A3728`, 우측 페이지 숫자 세리프. 좌측 섹션명 앞에 작은 원형 스탬프 축소판(지름 20px).
  - **본문 여백**: 좌우 88px, 상 44px / 하 64px. 세리프 본문 15pt, 행간 1.7.
  - **포인트 요소**: 중간 명도가 필요한 모든 면은 **45° 해칭 패턴**으로 처리 — 솔리드 면은 `#E0D5C3`(가장 밝은 면)와 `#1C130B`(반전 블록) 두 종류만.
  - 해칭 밀도 3단계(간격 4 / 6 / 10px)로 계조 확장.
  - 페이지당 `#1C130B` 반전 블록 1개(밝은 세리프 텍스트).
  - 표는 1px 룰 + 헤더 행만 해칭 면.
  - 리스트 불릿은 세리프 대시(–) 또는 4px 마름모.
  - 강조 수치는 세리프 64pt `#4A3728`, 아래 캡션 9pt 대문자 자간 +20%.
  - 이미지는 세피아 톤 변환 + 흰 여백 프레임 10px + 하단 캡션.
  - 종이 그레인 전 페이지 유지.
