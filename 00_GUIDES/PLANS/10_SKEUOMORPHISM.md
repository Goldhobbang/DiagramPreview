# 10. 스큐어모피즘 (Skeuomorphism)
> 실물의 재질·두께·조명을 화면에 그대로 옮긴다. **질감(texture) · 베벨(bevel) · 드롭섀도** 3종 세트가 필수.
> 뉴모피즘(05번)과 구분: 뉴모는 배경과 같은 색 단색, 여기는 **실제 재질 사진급 텍스처 + 다색**.

**공통 원칙**: 광원 좌상단 고정. 모든 표면에 (1) 재질 텍스처 (2) 1px 상단 하이라이트 / 1px 하단 섀도 베벨 (3) 외부 드롭섀도를 넣는다. 셋 중 하나라도 빠지면 재질이 안 산다.

## ◾ Variation 1: Leather Desk (가죽 데스크 · 스티치)

* **핵심 컬러 (HEX)**: 배경 가죽 `#6B4423` / 어두운 가죽 `#4A2E17` · 스티치 `#E8D5B0` · 페이지 `#F5EDDC`(양피지) · 포인트 `#8B0000`(북마크 레드) · 금 `#C0A062` · 텍스트 `#2E1F14` / 반전 `#F5EDDC`
* **사용 도형 & 그래픽**: 가죽 그레인 텍스처(불규칙 모공 패턴), **재봉 스티치 라인**(점선 4px on / 6px off, `#E8D5B0`, 안쪽 1px 그림자), 라운드 반경 12px, 금속 코너 캡, 리본 북마크. 그림자 `0 6px 16px rgba(0,0,0,0.45)` 진하게.
* **표지(Cover) 디자인**
  - 배경 전면 `#6B4423` 가죽 텍스처 + 가장자리로 갈수록 어두워지는 비네트 25%.
  - **중앙 액자 구조** — 화면 안쪽 여백 64px 지점에 스티치 라인이 사각으로 한 바퀴. 스티치 안쪽 면은 배경보다 한 단계 밝은 가죽(`#7D5230`)으로 눌린 자국(디보싱) 표현.
  - 그 안쪽 중앙에 양피지 라벨 패널(가로 62% × 세로 34%, `#F5EDDC`, 반경 4px, 가장자리 미세 찢김 + 드롭섀도 `0 4px 12px rgba(0,0,0,0.4)`).
  - 제목은 라벨 위 중앙 정렬, 세리프 40pt `#2E1F14`, 살짝 잉크 번짐 효과.
  - 라벨 네 모서리에 금색 압정(지름 14px, 방사형 그라데이션 + 하이라이트 점).
  - 좌측 상단에서 `#8B0000` 리본 북마크가 화면 위쪽 밖에서 들어와 아래로 늘어짐(폭 40px, V자 끝단, 접힘부에 그림자).
  - 우측 하단 가죽 위에 금색 각인(엠보싱) 로고 자리 — 텍스트를 안으로 눌러 넣은 효과(위 1px 어두운선 + 아래 1px 밝은선).
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 80px 어두운 가죽 밴드(`#4A2E17`) + 하단 경계에 스티치 1줄. 좌측 섹션명 `#E8D5B0` 세리프, 우측 금색 페이지 숫자.
  - **본문 여백**: 좌우 80px, 상 40px / 하 64px. 본문 영역 전체를 양피지 `#F5EDDC` 패널로 깔고(반경 6px, 드롭섀도), 가죽 배경 위에 얹음.
  - **포인트 요소**: 콘텐츠 구분은 양피지 위 가로 스티치 점선.
  - 리스트 불릿은 지름 8px 금색 압정.
  - 강조 문구는 `#8B0000` 세리프 + 밑줄 대신 옅은 잉크 하이라이트 얼룩.
  - 이미지는 사진 인화지처럼 흰 여백 8px + 살짝 회전(±1.5°) + 모서리 사진 코너 홀더.
  - 진행 표시는 우측 가장자리 리본 북마크 위치가 아래로 내려가며 표현.

## ◾ Variation 2: Brushed Metal (브러시드 메탈 · 계기판)

* **핵심 컬러 (HEX)**: 배경 메탈 `#9AA3AB` / 다크 메탈 `#5C666E` · 하이라이트 `#E8EDF1` · 유리 `#2B3138` · 포인트 `#00A3FF`(LED 블루), 보조 `#FF6B00`(LED 앰버) · 텍스트 `#1E252B` / 반전 `#E8EDF1`
* **사용 도형 & 그래픽**: **가로 방향 브러시드 메탈 텍스처**(1px 미세 가로선 랜덤 명도), 원통형 리니어 그라데이션(`#E8EDF1 → #9AA3AB → #6C757D → #9AA3AB` 90°), 육각 볼트, 원형 다이얼 게이지, 인셋 유리 디스플레이. V1 가죽(따뜻·유기적) → 여기는 **차갑고 기계적**.
* **표지(Cover) 디자인**
  - 배경 전면 브러시드 메탈 + 원통형 그라데이션(위·아래 어둡고 중앙 밝은 실린더 느낌).
  - **좌 40% : 우 60% 수직 분할 계기판 구조**(V1 중앙액자와 분리).
  - 좌측 40%: 대형 원형 다이얼 게이지(지름 화면 높이의 62%). 구성 — 바깥 메탈 베젤 링(그라데이션 + 상단 하이라이트) → 인셋 유리면(`#2B3138`, 안쪽 그림자) → 눈금 60개 + 숫자 → `#FF6B00` 바늘 + 중심 축 캡.
  - 우측 60%: 인셋 유리 디스플레이 패널(반경 8px, 안쪽 그림자 `inset 0 3px 8px rgba(0,0,0,0.6)`, 유리 위 대각 반사 스트릭 흰색 10%).
  - 제목은 그 유리 패널 안에 좌측 정렬, 42pt Bold `#00A3FF` + LED 글로우(blur 12px, 40%).
  - 패널 네 모서리에 육각 볼트 4개(지름 18px, 메탈 그라데이션 + 하단 그림자).
  - 하단에 메탈 토글 스위치·슬라이더 그래픽 3개 나열 — 발표자·날짜·버전 라벨 부착.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 72px 다크 메탈 밴드 + 상단 1px `#E8EDF1` 하이라이트 / 하단 1px 검정 베벨. 좌측 섹션명 각인, 우측 소형 유리 디스플레이 안 `03/24` LED 블루.
  - **본문 여백**: 좌우 72px, 상 40px / 하 56px.
  - **포인트 요소**: 콘텐츠 패널은 전부 인셋 유리(어두운 면 + 안쪽 그림자) — 메탈 배경 위 파인 창.
  - 각 패널 좌우에 육각 볼트 2개 고정.
  - 수치·데이터는 LED 세그먼트 서체 느낌으로 `#00A3FF`, 경고값만 `#FF6B00`.
  - 진행 바는 메탈 홈(인셋) + 안쪽 LED 필 + 필 상단 하이라이트.
  - 리스트 불릿은 지름 10px LED 원(점등 = 블루 글로우 / 소등 = `#5C666E`).
  - 유리면 반사 스트릭은 슬라이드마다 각도 동일하게 유지.

## ◾ Variation 3: Paper Notebook (노트·문구 · 책상 평면도)

* **핵심 컬러 (HEX)**: 배경 책상 `#C8B99C`(코르크) · 노트 `#F4EBD9` · 괘선 `#9DB8C9` · 마진선 `#E08A8A` · 포인트 `#F2C14E`(포스트잇), `#7FB069`(민트 메모) · 텍스트 `#2B3A42` / 필기 `#2F5D8A`
* **사용 도형 & 그래픽**: 모눈·괘선 종이, 스프링 바인딩(금속 코일), 포스트잇(모서리 말림 + 접착부 그림자), 클립·핀, 마스킹 테이프, 손글씨 밑줄. 종이 섬유 텍스처 6%. **위에서 내려다본 평면(top-down) 시점** — V1 액자·V2 계기판과 완전 다른 카메라.
* **표지(Cover) 디자인**
  - 배경 `#C8B99C` 코르크 텍스처 전면.
  - **비스듬한 오브젝트 산포 구조** — 책상 위에 물건이 놓인 듯 각 요소가 서로 다른 각도로 회전.
  - 중앙에 노트 한 권(가로 66% × 세로 72%, `#F4EBD9`, +2.5° 회전, 드롭섀도 `0 10px 24px rgba(0,0,0,0.28)`). 좌측 가장자리에 금속 스프링 코일 12개(원통 그라데이션 + 종이 구멍 안쪽 그림자).
  - 노트 면에 `#9DB8C9` 가로 괘선(간격 32px) + 좌측 `#E08A8A` 세로 마진선 1줄.
  - 제목은 노트 위 괘선에 **베이스라인을 정확히 맞춰** 좌측 정렬, 손글씨 계열 44pt `#2F5D8A`.
  - 노트 우측 상단에 `#F2C14E` 포스트잇(140×140, -6° 회전, 하단 모서리 말림 + 그 아래 짙은 그림자) — 안에 카테고리 라벨 손글씨.
  - 노트 좌측 하단에 `#7FB069` 작은 메모지(-3° 회전)에 날짜.
  - 노트 상단 모서리에 마스킹 테이프 조각(반투명 흰색 55%, 폭 90px, 15° 회전) 1개, 우측에 금속 클립.
  - 코르크 배경에 연필 1자루 대각 배치(우측 하단, 그림자 포함).
* **전역(Global) 디자인**
  - **상단 헤더**: 노트 패널 상단에 마스킹 테이프 조각 + 그 위 섹션명 손글씨. 우측 상단 모서리에 페이지 숫자를 괘선 위 작게.
  - **본문 여백**: 코르크 배경 여백 40px, 그 안 노트 패널이 콘텐츠 영역. 노트 내부 패딩 좌 88px(마진선 우측) / 우 64px / 상 56px.
  - **포인트 요소**: 노트 회전은 내지에서 **0°로 고정**(가독). 표지만 기울임.
  - 본문 텍스트는 반드시 괘선 베이스라인에 스냅 — 행간 = 괘선 간격 32px 배수.
  - 강조 항목은 포스트잇 조각 위에 올림(색상 2종 교대), 각 -4°~+4° 회전.
  - 리스트 불릿은 손그림 체크박스 ☐ 또는 지름 10px 원.
  - 표·다이어그램은 모눈 종이 영역(5mm 그리드)으로 배경 전환 후 작도.
  - 이미지는 폴라로이드 프레임(하단 여백 넓음) + 클립 고정 + 그림자.
