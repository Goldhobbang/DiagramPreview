# 09. 브루탈리즘 (Brutalism)
> 꾸미지 않은 날것. 시스템 기본 서체, 정렬되지 않은 여백, 노출된 구조. **장식은 거짓말**이라는 태도.
> 네오 브루탈리즘(11번)과 구분: 여기는 **컬러 블록·두꺼운 보더·그림자 없음**. 낡고 거칠고 불친절한 쪽.

**공통 원칙**: 서체는 시스템 기본(Arial / Times / Courier)만. 라운드 반경 0. 그림자·그라데이션 금지(V1 콘크리트 텍스처만 예외). 정렬은 의도적으로 어긋나게 — 단, 텍스트 자체 가독성은 유지.

---

## ◾ Variation 1: Raw Concrete (노출 콘크리트 · 구조 노출)

* **핵심 컬러 (HEX)**: 배경 `#B8B8B0`(콘크리트) · 면 `#9A9A92` / `#D2D2CA` · 포인트 `#1A1A1A` · 액센트 `#FF4A00`(안전색) · 텍스트 `#1A1A1A` / 보조 `#5C5C56`
* **사용 도형 & 그래픽**: 직각 사각형만. 콘크리트 텍스처(거친 그레인 12% + 얼룩 맵), 거푸집 이음선(1px 어두운 선 720px 간격), 노출 볼트 자국(지름 12px 원). 도면 치수선·화살표. 폰트: Helvetica/Arial Bold + Courier(메타 정보).
* **표지(Cover) 디자인**
  - 배경 `#B8B8B0` + 콘크리트 그레인 + 세로 거푸집 이음선 3줄.
  - **구조 노출 구조** — 화면에 12컬럼 그리드 가이드를 실제로 보이게 그림(`#9A9A92` 1px). 격자를 숨기지 않는 것이 콘셉트.
  - 제목은 좌측 상단에 붙여 배치(좌 여백 48px, 상 48px), Arial Black 72pt `#1A1A1A`, 행간 0.88 — 글자끼리 거의 닿게.
  - 제목을 그리드에 맞추지 않고 **일부러 2컬럼 어긋나게** 걸침.
  - 우측 하단에 `#FF4A00` 사각형 블록(가로 30% × 세로 12%) — 유일한 채도, 그 위 흰 Courier 12pt로 파일명·버전 표기.
  - 좌측 하단에 Courier 10pt 메타 블록: 날짜 / 작성자 / 버전 / 페이지 수를 줄바꿈 없이 나열.
  - 화면 상·좌 가장자리에 도면식 치수선(`#5C5C56` 1px + 양끝 화살표) + 실제 픽셀 수치 표기.
  - 볼트 자국 원 4개를 네 모서리 안쪽 40px 지점에 배치.
* **전역(Global) 디자인**
  - **상단 헤더**: 높이 60px, 상단에 `#1A1A1A` 4px 굵은 수평선. 그 아래 좌측 Courier 11pt 섹션명(대문자), 우측 `[ 03 / 24 ]` 대괄호 표기.
  - **본문 여백**: 좌 48px / 우 48px — 대칭이지만 콘텐츠는 좌측으로만 쏠리게 배치, 우측 25%는 의도적 공백.
  - **포인트 요소**: 카드 없음. 정보 블록은 `#1A1A1A` 2px 상단 선 + 그 아래 텍스트 나열로만 구분.
  - 표는 1px 선 격자 전체 노출(모던 테이블 금지 — 모든 셀 경계 표시).
  - 강조는 `#FF4A00` 배경 + 검정 텍스트 블록으로만. 슬라이드당 1회.
  - 이미지는 흑백 + 대비 강하게, 프레임 없이 그리드에 딱 맞춰 크롭.
  - 그리드 가이드 라인은 내지에서도 유지(불투명 40%).

## ◾ Variation 2: Terminal Green (터미널 · 모노스페이스)

* **핵심 컬러 (HEX)**: 배경 `#0A0A0A` · 포인트 `#00FF41`(포스포 그린) · 보조 `#008F11`(딤 그린) · 경고 `#FFB000`(앰버) · 텍스트 `#00FF41` / 보조 `#4A7A4A`
* **사용 도형 & 그래픽**: **모든 요소가 모노스페이스 문자로 그려짐** — 박스는 `┌─┐│└┘`, 구분선은 `═══`, 진행 바는 `[████░░░░]`. 도형 자체를 쓰지 않는 것이 규칙. CRT 스캔라인(2px 간격 검정 8%), 미세 포스포 글로우(blur 4px), 커서 블록 `▮`.
* **표지(Cover) 디자인**
  - 배경 `#0A0A0A` + 스캔라인 전면 오버레이.
  - **좌측 정렬 터미널 로그 구조**(V1 그리드노출과 완전 분리 — 여기는 순수 텍스트 흐름).
  - 화면 좌측 여백 64px에서 시작하는 모노스페이스 텍스트 블록이 위에서 아래로 흐름:
    ```
    $ ./presentation --init
    > loading assets............ OK
    > rendering deck............ OK
    ```
  - 제목은 그 로그 아래에 ASCII 박스로 감싸 배치:
    ```
    ┌──────────────────────────────┐
    │  프로젝트 제목이 여기 들어감      │
    └──────────────────────────────┘
    ```
    박스 안 텍스트 Courier Bold 36pt `#00FF41`, 박스 선은 `#008F11`.
  - 박스 아래 한 줄 띄고 `> ` 프롬프트 + 깜빡이는 커서 블록 `▮`.
  - 우측 상단에 `#FFB000` 앰버로 상태 표기 `[ STATUS: READY ]`.
  - 화면 하단에 `[████████░░░░░░░░] 47%` 형태 진행 바.
  - 그 외 도형 전무. 여백은 검정 그대로.
* **전역(Global) 디자인**
  - **상단 헤더**: `═══════════════` 이중선 한 줄 + 그 위에 `> SECTION_NAME` 형식. 우측에 `[03/24]`.
  - **본문 여백**: 좌 64px 고정(모든 줄이 같은 좌측 축에서 시작), 우 여백 자유. 상 48px.
  - **포인트 요소**: 리스트는 `- ` 또는 `> ` 접두. 불릿 도형 금지.
  - 강조는 배경 반전 — `#00FF41` 면 위 `#0A0A0A` 텍스트(터미널 셀렉션 느낌).
  - 경고·핵심은 `#FFB000` 앰버, 그 외 전부 그린 계열 2단계로만.
  - 표는 `|` `+--+` 로 작도한 ASCII 테이블.
  - 이미지 삽입 시 ASCII 아트 또는 1비트 디더링 변환 후 그린 단색.
  - 행간 1.5 고정, 자간 0 — 모노스페이스 격자가 깨지지 않게.

## ◾ Variation 3: Red Alert (하이 콘트라스트 · 대각 절단)

* **핵심 컬러 (HEX)**: 배경 `#FFFFFF` · 포인트 `#E4002B`(레드) · 딥 `#000000` · 보조 면 `#EDEDED` · 텍스트 `#000000` / 반전 `#FFFFFF`
* **사용 도형 & 그래픽**: 3색만(흑·백·적). 굵은 검정 사선 스트라이프(폭 24px, 45°), 대각 절단면, 화살표 삼각형, 경고 테이프 패턴. 하프톤 없음, 순수 면. V1 텍스처 · V2 문자기반 → 여기는 **대형 면 대비**.
* **표지(Cover) 디자인**
  - 배경 `#FFFFFF`. **대각 절단 구조** — 화면을 좌상단→우하단 방향 -22° 대각선 하나로 두 조각으로 자름.
  - 위쪽 조각: 흰색 유지. 아래쪽 조각: `#E4002B` 단색 채움.
  - 제목은 대각선을 **가로질러** 배치, Arial Black 88pt, 행간 0.85. 대각선 위 구간은 `#000000`, 아래 구간은 `#FFFFFF`로 **글자 색이 절단면에서 갈라짐**(텍스트를 대각선으로 마스킹) — 표지의 핵심 장치.
  - 좌측 상단에 검정 사선 스트라이프 블록(가로 200px × 세로 60px) — 경고 테이프.
  - 우측 하단 레드 면 위에 흰색 큰 삼각형 화살표(한 변 120px)가 우하 방향을 가리킴.
  - 하단 좌측에 Arial 11pt 검정 메타 정보, 자간 +6%.
  - 화면 우측 가장자리를 따라 세로로 반복되는 대문자 텍스트 스트립(90° 회전, 8pt, 자간 +40%).
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 전폭 `#000000` 바(높이 56px) + 흰 텍스트 섹션명 좌측. 바 우측 끝에서 안쪽으로 `#E4002B` 사각형(가로 80px)이 물려 들어감.
  - **본문 여백**: 좌우 56px, 상 32px / 하 48px.
  - **포인트 요소**: 콘텐츠 블록은 3px `#000000` 굵은 보더 + 흰 배경, 반경 0, 그림자 없음.
  - 블록 중 하나는 반드시 `#E4002B` 반전(흰 텍스트) — 페이지당 1개 앵커.
  - 섹션 구분은 검정 사선 스트라이프 띠(높이 24px) 전폭.
  - 리스트 불릿은 검정 정삼각형 10px(우측 방향).
  - 수치·데이터는 Arial Black 64pt 검정, 단위만 레드.
  - 이미지는 1비트 흑백 변환(중간톤 제거) 또는 레드 듀오톤.
