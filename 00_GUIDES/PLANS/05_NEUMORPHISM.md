# 05. 뉴모피즘 (Neumorphism)
> 배경과 같은 색의 표면이 밀려 나오거나(Extruded) 눌려 들어간(Inset) 이중 그림자로만 형태를 만든다. 색 대비가 아니라 **빛의 방향**이 유일한 조형 언어.

**공통 스펙**: 광원은 항상 좌상단 135° 고정. 그림자 2개 1세트 — 밝은 쪽(좌상)과 어두운 쪽(우하). 요소와 배경은 **반드시 같은 HEX**. 반경 16~32px. 채도 높은 색은 포인트로만, 면적 10% 이내.

---

## ◾ Variation 1: Soft Gray (클래식 소프트 UI)

* **핵심 컬러 (HEX)**: 배경·표면 `#E0E5EC`(동일) · 밝은 그림자 `#FFFFFF` / 어두운 그림자 `#A3B1C6` · 포인트 `#5B7FFF` · 텍스트 `#3E4A5B` / 보조 `#8494A8`
* **사용 도형 & 그래픽**: 반경 24px 라운드 사각형, 정원 버튼, 알약형 슬라이더 트랙. 그라데이션은 표면에 아주 얕게(`#E8EDF3 → #D8DEE7` 145°)만. 테두리·선 사용 금지 — 형태는 그림자로만.
  - 돌출: `box-shadow: -8px -8px 16px #FFFFFF, 8px 8px 16px #A3B1C6`
  - 함몰: `box-shadow: inset -6px -6px 12px #FFFFFF, inset 6px 6px 12px #A3B1C6`
* **표지(Cover) 디자인**
  - 전면 `#E0E5EC`. 분할선 없음 — **중앙 집중 단일 오브젝트 구조**.
  - 화면 정중앙에 돌출 라운드 사각형 패널(가로 66% × 세로 44%, 반경 32px).
  - 그 패널 **안쪽에** 다시 함몰 처리된 얕은 홈(가로 80% × 세로 34%, 반경 20px)을 파고, 제목을 그 홈 안에 중앙 정렬 배치 — 돌출 안의 함몰 이중 구조가 이 스타일의 핵심.
  - 제목 38pt Semi Bold `#3E4A5B`. 텍스트에 1px 흰색 상단 이너 하이라이트로 각인 느낌.
  - 패널 좌측 상단 바깥에 지름 72px 돌출 정원 1개(아이콘 슬롯), 패널 우측 하단 바깥에 지름 48px 돌출 정원 1개.
  - 발표자·날짜는 패널 아래 32px 지점, 12pt `#8494A8`, 그림자 없이 평면 텍스트.
* **전역(Global) 디자인**
  - **상단 헤더**: 전폭 바 없음. 좌측 상단에 **함몰형 알약 캡슐**(높이 40px, 반경 20px) 안에 섹션명. 우측 상단에 돌출 정원(지름 40px) 안 페이지 숫자.
  - **본문 여백**: 좌우 72px, 상 48px / 하 64px. 요소 간 간격은 최소 32px — 그림자가 서로 먹지 않도록 넉넉히.
  - **포인트 요소**: 콘텐츠 카드는 전부 돌출(반경 24px). 선택·강조 상태의 카드만 **함몰**로 전환해 "눌린 상태"로 표현 — 색 대비 대신 깊이 대비.
  - 아이콘은 항상 돌출 정원 안에 `#5B7FFF` 2px 스트로크.
  - 진행 바(progress)는 함몰 트랙 + 돌출 `#5B7FFF` 필.
  - 금지: 그림자 위 그림자 3중 중첩, 카드끼리 겹치기.

## ◾ Variation 2: Warm Clay (웜 클레이 · 좌우 비대칭)

* **핵심 컬러 (HEX)**: 배경·표면 `#EDE4DA` · 밝은 그림자 `#FFFAF4` / 어두운 그림자 `#C4B3A2` · 포인트 `#C96F4A`(테라코타) · 텍스트 `#4A3B2F` / 보조 `#9A8574`
* **사용 도형 & 그래픽**: V1의 정직한 사각형 대신 **유기적 형태** — 반경 불균등 라운드(`border-radius: 60px 24px 60px 24px`), 물방울형, 도톰한 원. 표면에 미세 세라믹 그레인 4%. 그림자 blur를 V1보다 크게(24px) 해 더 물렁한 촉감.
* **표지(Cover) 디자인**
  - 전면 `#EDE4DA` + 그레인.
  - **좌 38% : 우 62% 비대칭 수직 구조**(V1 중앙집중과 완전 분리).
  - 좌측 38% 영역에 세로로 긴 돌출 패널(가로 100%, 세로 74%, 반경 `0 80px 80px 0` — 우측만 크게 둥근 형태)이 화면 왼쪽 끝에서 밀려 나옴.
  - 제목은 우측 62% 빈 영역에 좌측 정렬, 44pt Bold `#4A3B2F`. 배경 위 평면 텍스트(그림자 없음)로 두어 좌측 입체 패널과 대비.
  - 제목 첫 줄 왼쪽에 지름 20px 돌출 정원 `#C96F4A` 1개 — 유일한 채도.
  - 좌측 패널 안에는 크기가 다른 함몰 원 3개(지름 96 / 64 / 40px)를 세로로 리듬감 있게 배열.
  - 우측 하단 모서리에 물방울형 돌출 도형(180×140, 불균등 반경) 하나가 화면 밖으로 1/3 걸침.
* **전역(Global) 디자인**
  - **상단 헤더**: 좌측 상단에 불균등 반경 돌출 태그(`border-radius: 20px 4px 20px 4px`) 안 섹션명. 표지의 유기적 반경 규칙 승계.
  - **본문 여백**: 좌 96px / 우 72px(비대칭 유지), 상 56px.
  - **포인트 요소**: 콘텐츠 카드마다 반경 조합을 좌우 교대로 뒤집어(`60px 24px` ↔ `24px 60px`) 페이지에 리듬 부여.
  - 리스트 불릿은 지름 12px 함몰 원(파인 점).
  - 강조 수치는 `#C96F4A` 52pt, 돌출 원형 배지 안에 배치.
  - 이미지는 사각 프레임 금지 — 반드시 불균등 라운드 마스크 + 함몰 그림자로 액자 처리.

## ◾ Variation 3: Night Soft (다크 뉴모 · 하단 스택)

* **핵심 컬러 (HEX)**: 배경·표면 `#2E3239` · 밝은 그림자 `#3A3F48` / 어두운 그림자 `#1E2127` · 포인트 `#4FD1A5`(민트) · 텍스트 `#E4E7EC` / 보조 `#8A919C`
* **사용 도형 & 그래픽**: 다크 뉴모는 밝은 그림자 대비가 약하므로 **blur 작게(10~14px), 오프셋 크게(10px)** 로 설정해 형태 유지. 각진 편의 반경 16px 사각형 위주. 포인트 민트에만 얕은 글로우 허용(blur 16px, 20%).
  - 돌출: `box-shadow: -10px -10px 14px #3A3F48, 10px 10px 14px #1E2127`
* **표지(Cover) 디자인**
  - 전면 `#2E3239`. **하단 정렬 수평 스택 구조**(V1 중앙 · V2 좌측비대칭과 분리).
  - 화면 상단 55%는 완전히 비우고, 하단 45%에 가로로 긴 돌출 패널 3개를 **계단식으로 겹쳐 쌓음**:
    - 가장 뒤 패널: 가로 92%, 높이 220px, 좌우 여백 4%
    - 중간 패널: 가로 84%, 높이 200px, 아래로 24px 내려 배치
    - 앞 패널: 가로 76%, 높이 180px, 다시 24px 아래 — 카드 덱이 쌓인 형태
  - 제목은 **비어 있는 상단 55% 영역** 좌측 하단에 배치(좌 여백 88px), 50pt Light `#E4E7EC`. 여백과 스택의 대비가 표지의 핵심.
  - 앞 패널 안쪽에 함몰 홈(가로 60%, 높이 8px, 반경 4px) + 그 안에 `#4FD1A5` 돌출 필 40% 길이 — 진행 인디케이터.
  - 우측 상단에 지름 56px 돌출 정원 1개, 안에 민트 2px 스트로크 아이콘.
* **전역(Global) 디자인**
  - **상단 헤더**: 상단 우측에 돌출 알약(높이 36px) 안 페이지 진행 `03 / 24`, 좌측에 평면 섹션명 12pt `#8A919C`.
  - **본문 여백**: 좌우 80px, 상 52px / 하 72px.
  - **포인트 요소**: 콘텐츠 영역 자체를 **하나의 큰 함몰 패널**(반경 24px)로 파고, 그 안에 작은 돌출 카드들을 올림 — 함몰 안의 돌출(V1 반대 구조).
  - 차트는 함몰 트랙 + 민트 돌출 바. 데이터 라벨은 `#8A919C`.
  - 텍스트 순백 금지(`#E4E7EC` 고정). 민트는 슬라이드당 2회 이내.
  - 다크 뉴모 주의: 표면 위 표면 3단 중첩 시 형태 소실 — 최대 2단까지만.
