# 03. 임포트 체크리스트

HTML 하나를 Figma로 옮길 때마다 이 문서를 위에서 아래로 훑는다.
복사해서 PR 설명이나 이슈에 붙여 써도 된다.

---

## A. 임포트 **전** — 브라우저에서 확인

로컬 서버(`python -m http.server 8000`)로 열어서 확인한다. `file://`로 열면
상대경로 CSS/폰트가 막힐 수 있다.

### 레이아웃
- [ ] 브라우저를 정확히 **1920 폭**으로 확인 (DevTools 디바이스 모드 → Responsive → `1920 × 1080`, 줌 100%)
- [ ] `.slide` 밖으로 삐져나온 요소 없음
  - 확인법: `<body class="debug">` 추가 → 모든 박스 경계에 빨간 아웃라인 표시
- [ ] 세이프 영역(패딩 96px)을 침범한 텍스트 없음
- [ ] 요소가 세로로 잘리지 않음 — 특히 카드 안 긴 텍스트
- [ ] 한글 받침 잘림 없음 (`line-height` 1.5 이상인지)

### 에셋
- [ ] 깨진 이미지 아이콘 0개
- [ ] DevTools Console에 404 없음
- [ ] DevTools Network에서 폰트 파일이 실제 200으로 로드됨
- [ ] 웹폰트가 실제 적용됨
  - 확인법: 텍스트 선택 → DevTools **Computed → font-family**가 fallback(예: `sans-serif` 단독)이 아닌지

### 정적 상태
- [ ] 애니메이션·트랜지션이 **최종 상태**로 정지되어 있음 (플러그인은 정지 화면을 캡처)
- [ ] `:hover` 로만 보이는 콘텐츠 없음
- [ ] 스크롤해야 보이는 콘텐츠 없음

### 코드 위생
- [ ] 색상 하드코딩 없음 — 전부 `var(--color-*)`
- [ ] 간격이 8px 배수
- [ ] `position: absolute` 최소화 (Auto Layout 변환을 위해)
- [ ] `class` 이름이 의미 있음 (`div1`, `box2` 같은 이름 없음)
- [ ] `<div>` 중첩 4단계 이내

---

## B. 임포트 **직전** — 플러그인 설정

- [ ] Viewport = **Custom `1920 × 1080`** (프리셋 아님)
- [ ] 임포트 방식 = **URL** (GitHub Pages 주소)
- [ ] Figma 파일에 해당 웹폰트가 설치/활성화되어 있음
- [ ] 붙여넣은 URL을 브라우저에서 먼저 열어 200 확인

---

## C. 임포트 **후** — Figma에서 확인

### 구조
- [ ] 최상위 프레임 크기가 정확히 **1920 × 1080**
- [ ] 레이어 중첩 **3~4단계 이내** (더 깊으면 HTML 단순화 후 재임포트)
- [ ] `display:flex` 컨테이너가 **Auto Layout**으로 변환됨
- [ ] 레이어 이름이 의미 있음 (`div` 도배 아님)
- [ ] 빈 프레임 / 0×0 레이어 없음

### 텍스트
- [ ] 텍스트가 **편집 가능한 텍스트 레이어** (이미지로 래스터화되지 않음)
- [ ] 상단에 **"Missing fonts"** 경고 배너 없음
- [ ] 폰트 굵기(Weight)가 브라우저와 동일
- [ ] 줄바꿈 위치가 브라우저와 동일
- [ ] 자간·행간 육안 비교 시 차이 없음

### 시각 요소
- [ ] 색상값이 브라우저와 일치 (스포이드로 1~2곳 대조)
- [ ] `border-radius` 유실 없음
- [ ] `box-shadow` 유실 없음
- [ ] SVG가 벡터 레이어로 들어옴 (단일 이미지로 뭉치지 않음)
- [ ] 반투명(`opacity`, `rgba`) 값 유지
- [ ] 이미지 비율 왜곡 없음

### 마감
- [ ] 프레임 이름을 컴포넌트/슬라이드 이름으로 변경
- [ ] 재사용할 요소는 컴포넌트화 (`Ctrl/Cmd + Alt + K`)
- [ ] 색상을 Figma 변수/스타일로 등록

---

## D. 실패 시 대응표

| 증상 | 원인 | 조치 |
|---|---|---|
| 텍스트가 이미지로 들어옴 | 웹폰트 미로드 또는 Figma에 폰트 없음 | Figma에 폰트 설치 → 재임포트 |
| "Missing fonts" 배너 | 동일 | 동일 |
| 스타일이 전혀 안 먹음 | Paste HTML 모드 + 상대경로 CSS | URL 임포트로 전환 |
| 이미지만 안 나옴 | 상대경로 오류 / Pages 미배포 | 해당 URL을 브라우저에서 직접 열어 404 확인 |
| 줄바꿈 위치가 다름 | 뷰포트가 1920이 아님 | Viewport를 Custom 1920×1080으로 |
| 요소가 잘려 있음 | `.slide` 오버플로우 | 브라우저에서 먼저 수정 후 재임포트 |
| Auto Layout이 안 잡힘 | `position:absolute` 또는 `grid` 사용 | `flex` + `gap`으로 변경 |
| 레이어가 수백 개 | `div` 과다 중첩 | 구조 단순화 후 재임포트 |
| 아이콘이 한 덩어리 | `<img src="*.svg">` | 인라인 `<svg>`로 교체 |
| 그림자가 사라짐 | 다중 `box-shadow` | 단일 그림자로 축소 |
| 배경이 불투명하게 나옴 | `backdrop-filter` / `mix-blend-mode` | `rgba()` 반투명으로 대체 |

---

## E. 최소 회귀 확인 (컴포넌트 신규 추가 시)

새 다이어그램을 만들었다면 최소한 이것만은 한다.

1. 로컬 서버로 열어 **1920 폭**에서 육안 확인
2. `docs/manifest.json`에 항목 추가 (또는 `status`를 `done`으로 변경)
3. 갤러리(`localhost:8000/docs/`)에서 축소 썸네일이 정상 렌더되는지 확인
4. push → Pages 배포 후 해당 URL이 200인지 확인
5. Figma에 1회 임포트해서 위 **C** 섹션 통과 확인
