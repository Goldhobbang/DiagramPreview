# 06. 컴포넌트 카탈로그 (16종)

`02_COMPONENTS_LIBRARY/` 의 다이어그램을 제외한 나머지 **기획 목록**.
다이어그램 31종은 [04_DIAGRAM_CATALOG.md](04_DIAGRAM_CATALOG.md) 를 본다.

> 이 문서는 "무엇을 만들 것인가"의 기획서다. **진척 현황은 여기서 보지 않는다.**
> 실제 상태는 갤러리(`docs/`)가 파일을 스캔해 자동으로 보여준다.

작성 규칙은 다이어그램과 완전히 동일하다 — 중복 서술하지 않는다:
[02_COMPONENTS_LIBRARY/03_DIAGRAMS/_README.md](../02_COMPONENTS_LIBRARY/03_DIAGRAMS/_README.md)
의 **필수 규칙 6가지** + **파일 골격**을 그대로 따른다.
(1행 `@card` 마커 · 자기완결형 CSS 인라인 · 색은 변수만 · 도형은 인라인 SVG ·
글자는 HTML · flex+gap · 실제 한글 문구 · JS 0줄)

크기는 각 파일에 **이미 들어 있는 `@card` 마커 값**이 단일 소스다. 아래 표는 그 사본이며,
크기를 바꿀 때는 마커를 고치고 `node tools/build-gallery.js`를 다시 돌린다.

---

## 01_TYPOGRAPHY — 타이포그래피 (3종)

토큰 견본이 아니라 **실제 슬라이드 본문 조판**을 보여주는 것이 목적이다.
값은 전부 `--fs-*` / `--lh-*` / `--fw-*` 토큰을 참조한다.

| # | 파일 | 용도 | 구성 요소 | 크기 |
|---|---|---|---|---|
| 1 | `heading_scale.html` | 제목 위계 결정 시 대조 | Display 96 → Caption 18 7단계. 각 행에 토큰명·px 병기 | 1400×900 |
| 2 | `body_text_blocks.html` | 텍스트 위주 슬라이드 조판 | 리드 단락 + 본문 2단 + 인용(좌측 accent 바) + 각주 | 1400×700 |
| 3 | `list_styles.html` | 불릿 목록 스타일 선택 | 4종 2×2 — 점 불릿 · 번호 원 · 체크 · 화살표(SVG 아이콘) | 1400×700 |

## 02_CHARTS — 차트 (6종)

**도형은 인라인 `<svg>`, 값·축 라벨은 HTML 요소**로 분리한다. Figma에서 막대는 벡터,
숫자는 편집 가능한 텍스트가 되어야 한다. 계열 색은 `--color-data-1~6` 순서대로.

| # | 파일 | 용도 | 구성 요소 | 크기 |
|---|---|---|---|---|
| 1 | `bar_vertical.html` | 카테고리 5~6개 비교 | Y축 눈금선 4줄 + 세로 막대 + 상단 값 라벨 + X축 라벨 | 1200×700 |
| 2 | `bar_horizontal.html` | 항목명이 긴 순위 비교 | 좌측 항목명 + 가로 막대 6개 + 우측 값, 1위 accent 강조 | 1200×700 |
| 3 | `line_trend.html` | 분기별 추이 2계열 | 눈금선 + 폴리라인 2개 + 데이터 포인트 원 + 범례 | 1400×700 |
| 4 | `donut_share.html` | 구성비 4~5항목 | `stroke-dasharray` 도넛 + 중앙 총합 + 우측 범례(색·이름·%) | 1000×700 |
| 5 | `stacked_composition.html` | 기간별 구성 변화 | 5기간 × 4계열 누적 막대 + 100% 기준선 + 범례 | 1400×700 |
| 6 | `kpi_number_cards.html` | 표지 다음 요약 슬라이드 | `.stat` 4장 가로 + 증감률 배지(▲▼) + 보조 설명 | 1400×400 |

## 04_TABLES — 표 (3종)

표는 SVG를 쓰지 않는다 — `<table>` 이 Figma에서 행·열 프레임으로 들어온다.
세로선을 만들지 않고 **가로 구분선 + 헤더 배경**으로만 구분한다(프로젝터 가독성).

| # | 파일 | 용도 | 구성 요소 | 크기 |
|---|---|---|---|---|
| 1 | `comparison_table.html` | 3~4 옵션 다항목 비교 | 헤더 행 강조 + 줄무늬 + ●◐○ 평가 심볼 + 추천 열 accent | 1400×700 |
| 2 | `pricing_table.html` | 요금제 제안 | 3열 카드형, 중앙 추천 플랜 확대·배지 + 기능 체크 목록 | 1400×800 |
| 3 | `spec_sheet.html` | 제품·시스템 사양 나열 | 라벨-값 2열 × 2블록, 섹션 소제목 + 얇은 구분선 | 1200×800 |

## 05_UI_PARTS — UI 부품 (4종)

한 파일에 **변형(variant)을 나열하는 견본판**이다. 슬라이드에 얹을 때 필요한 한 개만
복사해 쓴다. `03_components.css` 의 `.badge` / `.card` / `.divider` 를 최대한 재사용한다.

| # | 파일 | 용도 | 구성 요소 | 크기 |
|---|---|---|---|---|
| 1 | `badges_tags.html` | 상태·분류 라벨 | 상태 배지 4색(진행/완료/보류/위험) + 아웃라인 태그 + 숫자 배지 | 1200×500 |
| 2 | `callout_boxes.html` | 주의·요약 강조 | 정보 · 주의 · 성공 · 경고 4종. 좌측 4px accent 바 + 아이콘 | 1200×700 |
| 3 | `icon_bullet_rows.html` | 기능 소개 목록 | 아이콘 원 + 제목 + 설명 행 4개, 2열 배치 | 1200×700 |
| 4 | `progress_indicators.html` | 진행률·성숙도 표시 | 가로 진행 바 3개 + 원형 게이지 2개 + 단계 스테퍼 | 1200×600 |
