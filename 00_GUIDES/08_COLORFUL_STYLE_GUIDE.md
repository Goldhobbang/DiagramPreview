# 08. 컬러풀 스타일 패밀리 (04_BOLD_POP · 05_PASTEL_PLAYFUL)

기존 3스타일(01~03)은 전부 **색을 억제**하는 쪽이다 — accent 면적 10% 이하,
그라디언트 1곳, 무채색 강조. 이 패밀리는 반대 방향: **화면에 색이 많아 보이는**
표지·간지 계열을 위해 존재한다. 규칙이 다르므로 문서를 분리한다.

같은 HTML을 `_style.css`만 바꿔 두 인상으로 만든다. **HTML은 절대 수정하지 않는다**
— [06_STYLE_IDENTITY.md](06_STYLE_IDENTITY.md)와 동일한 원칙.

각 스타일의 실제 값은 `01_TEMPLATES_BY_STYLE/<스타일>/_style.css` 에 들어 있다.
현재 이 패밀리는 표지(01_cover) + 섹션 구분(02_section_divider) 2장만 제공한다.

---

## 핵심 원칙 — 색은 도형에, 텍스트는 잉크로

1. **본문 텍스트는 항상 무채색** (`--color-text` / `--color-text-muted`).
   유채색 텍스트는 프로젝터에서 대비가 무너진다. 색은 장식 도형·구분자 전용.
2. **장식 면적 합계 35% 이하, 한 도형 15% 이하.**
   기존 "accent 10%" 규칙의 이 패밀리 대체 규칙이다. "많음"의 인상은 큰 면 하나가
   아니라 **작은 조각 여러 개**로 만든다.
3. **색은 `--color-data-1`부터 순서대로.** 건너뛰지 않는다. 6개를 넘으면 1부터 반복.
4. **강조 대상은 여전히 1개.** 컬러풀은 장식 밀도 얘기지 위계 파괴가 아니다.
   1차 정보(대제목·섹션명)는 잉크색 크기/굵기로 세운다.
5. **색만으로 구분하지 않는다.** 진행 도트에는 반드시 단계 라벨 텍스트를 병기한다.
   `filter:grayscale(1)`을 걸어도 현재 단계가 식별돼야 한다.
6. **장식은 텍스트 영역을 침범하지 않는다.** 표지는 우측 밴드, 간지는 우측 하단
   사분면에만. 세이프 영역(96px) 안의 텍스트 컬럼과 겹치지 않게 한다.

## 04_BOLD_POP — 대담

**규칙**
- 구분은 그림자가 아니라 **굵은 잉크 라인**(`--border-w` 2px). 팝 아트 문법.
- 장식 조각은 각진 사각·삼각·원 혼합. 겹침 배치 허용 (단 텍스트 위 금지)
- 원색끼리 인접 배치할 때 같은 계열(레드↔핑크)을 붙이지 않는다 — data 순서대로면 안전

**하지 말 것**
- 유채색 텍스트 (제목을 빨강으로 칠하고 싶으면 이 스타일이 아니라 배너다)
- 그라디언트 — 원색 팝은 단색 면이 생명
- 그림자 — 잉크 라인과 그림자를 섞으면 문법이 무너진다

## 05_PASTEL_PLAYFUL — 친근

**규칙**
- 도형은 **둥근 blob**(원·캡슐·큰 라운드 사각)만. 뾰족한 꼭짓점 금지
- 그림자는 `--shadow-sm` 한 단계, 웜 톤(`rgba(61,56,51,…)`)만
- 파스텔은 흰 배경 대비가 약하므로 **작은 도형(56px 미만)에 쓰지 않는다** —
  칩·도트처럼 작아지면 안 보인다. 작은 요소는 진한 잉크색으로

**하지 말 것**
- 채도 높은 원색 혼입 (한 장 안에서 Bold Pop과 섞지 않는다)
- 파스텔 배경 위 파스텔 텍스트 — 대비 2:1도 안 나온다
- 아웃라인 — 부드러움이 깨진다. 구분이 필요하면 여백으로

## 스타일 추가하는 법 (이 패밀리에)

1. `01_TEMPLATES_BY_STYLE/06_<NAME>/` 생성
2. `_style.css`에 **변수 오버라이드만** 작성. 새 클래스·셀렉터 정의 금지.
   장식 팔레트는 `--color-data-1~6`을 그 스타일 톤으로 다시 뽑는다
3. 기존 패밀리 스타일의 2개 HTML(01_cover, 02_section_divider)을 **내용 그대로** 복사
4. 위 비교표에 열 추가, `tools/build-gallery.js`의 `LABELS`에 표시명 추가
5. `node tools/build-gallery.js` 실행해 갤러리 반영

**HTML을 고쳐야 스타일이 나온다면 그건 스타일이 아니라 레이아웃이다.**
그 값을 변수로 빼서 `01_variables.css`에 추가한 뒤 다시 시도한다.

---

## 검증

```bash
node tools/build-gallery.js
npx serve -l 8000 .
```

갤러리(`/docs/`) 슬라이드 템플릿 섹션에서 Bold Pop / Pastel Playful 그룹 확인.

- [ ] 두 스타일이 한눈에 구별되는가 (원색 vs 파스텔)
- [ ] 텍스트에 유채색이 없는가
- [ ] 장식 합계가 화면의 1/3을 넘지 않는가
- [ ] `filter:grayscale(1)`을 걸어도 진행 단계가 라벨로 식별되는가
- [ ] 장식이 텍스트 컬럼·세이프 영역 텍스트와 겹치지 않는가
