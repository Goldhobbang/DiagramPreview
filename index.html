CORE PRINCIPLES

왜 고정 HTML 슬라이드 시스템인가

웹 반응형 문법을 버리고 발표용 16:9 캔버스와 Figma 변환 정확도에만 집중했습니다.

01

1920×1080 고정 캔버스 · PX 전용

rem·vw·미디어쿼리를 쓰지 않고 모든 치수를 정확한 px로 고정해 브라우저 화면과 Figma 임포트 결과 사이의 계산 오차를 원천 차단합니다.

02

CSS 변수 기반 즉시 테마 전환

색상(--color-*), 간격(--sp-*), 타이포 스케일(--fs-*)이 의미 기반 토큰으로 분리되어 HTML 수정 없이 브랜드 테마를 교체할 수 있습니다.

03

Figma Auto Layout 직결 구조

도형·커넥터는 인라인 벡터 SVG로, 텍스트와 카드 배치는 flex + gap으로 작성해 Figma 임포트 즉시 편집 가능한 Auto Layout과 텍스트 레이어로 변환됩니다.

WORKFLOW

3단계 Figma 가져오기 절차

스크린샷이나 별도 빌드 파이프라인 없이 URL 복사 한 번으로 끝납니다.

  1. STEP 1

    갤러리에서 URL 복사

    프리뷰 갤러리에서 원하는 슬라이드나 다이어그램 카드를 고르고 [URL 복사] 버튼을 누릅니다.

  2. STEP 2

    html.to.design 실행

    Figma에서 html.to.design 플러그인을 열고 Viewport 크기를 Custom 1920 × 1080으로 맞춥니다.

  3. STEP 3

    붙여넣기 및 즉시 편집

    복사한 주소를 붙여넣으면 폰트, 간격, 벡터 도형, Auto Layout이 살아 있는 Figma 프레임이 즉시 생성됩니다.
