# 03_ASSETS — 공통 리소스

모든 템플릿·컴포넌트가 상대경로로 참조하는 공용 자산. **여기 파일을 고치면 전체에 반영된다.**

## css/

| 파일 | 역할 | 고쳐도 되나 |
|---|---|---|
| `00_reset.css` | 슬라이드 전용 최소 리셋 | 거의 안 고침 |
| `01_variables.css` | **디자인 토큰 단일 소스** (색·폰트·간격) | 토큰 추가 시 |
| `02_slide_base.css` | `.slide` / `.component` 캔버스, 그리드, 타이포 유틸 | 신중히 |
| `03_components.css` | 2곳 이상에서 반복되는 공통 컴포넌트만 | 반복 발견 시 |

**로드 순서는 고정이다.** `00 → 01 → 02 → 03 → _style.css`
순서를 바꾸면 변수가 정의되기 전에 참조되어 조용히 무시된다.

`03_components.css`에 뭘 올릴지 기준: **서로 다른 파일 2개 이상에서 똑같이 반복될 때만.**
한 곳에서만 쓰는 건 해당 HTML의 `<style>`에 둔다.

## fonts/

폰트 파일 위치. 라이선스 메모는 [fonts/_README.md](fonts/_README.md) 참조.

## images/

슬라이드에 들어가는 사진·일러스트.
- 파일명: `<용도>_<설명>.jpg` (예: `cover_office_bg.jpg`)
- 1920 폭 배경 이미지는 **최소 1920px, 200KB 이하**로 압축
- `background-image` 대신 `<img>` 사용 (Figma에서 별도 이미지 레이어가 됨)

## icons/

아이콘 SVG.
- **인라인 `<svg>`로 복붙해서 쓴다.** `<img src="*.svg">`는 Figma에서 단일 이미지로 뭉친다
- 여기 파일은 원본 보관용
- `fill="currentColor"`로 저장하면 CSS `color`로 색을 제어할 수 있다
