# 99_DRAFTS — 작업/테스트용

> ⚠️ **이 폴더의 내용은 예고 없이 삭제된다.** 보존할 것은 여기 두지 않는다.

## 용도

- 새 다이어그램 아이디어 스케치
- CSS 실험, 레이아웃 시행착오
- 임포트 테스트용 임시 HTML
- 남의 슬라이드에서 참고용으로 뜯어온 조각

## 규칙

- 파일명 자유. 번호 체계 지킬 필요 없음
- 완성되면 **적절한 폴더로 이동**하고 여기서 지운다
  - 다이어그램 → `02_COMPONENTS_LIBRARY/03_DIAGRAMS/<카테고리>/`
  - 슬라이드 → `01_TEMPLATES_BY_STYLE/<스타일>/`
- 여기 파일은 `docs/manifest.json`에 등록하지 않는다 (갤러리에 안 나옴)
- 주기적으로 통째로 비운다
